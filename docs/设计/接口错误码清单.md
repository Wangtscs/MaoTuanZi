## 一、编码规则

格式：`ABCDEFG`（6 位数字）

| 位置 | 含义 |
|------|------|
| A | 模块（1=通用 2=用户 3=宠物 4=AI 5=订单 6=会员 7=工具 8=社交 9=系统） |
| B | 类别（0=成功 1=参数 2=鉴权 3=权限 4=资源 5=状态 6=三方 3=限流 9=系统） |
| CDE | 具体编号 |

## 四、前端处理原则

1. **不要直接展示 code** —— 转换为用户友好文案
2. **不要重复展示 message** —— 后端文案可能含技术细节
3. **网络错误兜底** —— 离线场景单独处理
4. **401 必须跳登录** —— 自动 refresh 失败时强制跳登录页
5. **5xx 统一提示** —— "服务异常，请稍后再试"
