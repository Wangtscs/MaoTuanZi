# 毛团子AI · UIUX 视觉规范与组件库

**版本**：V2.1 | **更新日期**：2026-08-18 | **关联文档**：`docs/设计/03-信息架构与页面流程图.md`、`docs/设计/品牌与文案规范.md`

> 本文档是 UI 设计的**基线规则**。去套话、聚焦可直接执行的规则。以 iPhone 14（390×844）为基准设计，小程序开发使用 `rpx` 单位。

## 三、组件库规范

### 3.1 按钮

| 类型 | 背景 | 文字 | 边框 | 用途 |
|------|------|------|------|------|
| 主按钮 | 毛团粉 `#FFB6C1` | 白色 | 无 | 主要操作 |
| 次按钮 | 白色 | 毛团粉 | 1px 毛团粉 | 次要操作 |
| 文字按钮 | 透明 | 主文字色 | 无 | 弱操作 |
| 危险按钮 | 错误红 | 白色 | 无 | 删除、退出 |
| 禁用按钮 | `#E0E0E0` | `#999999` | 无 | 不可点击 |

**尺寸**：

| 尺寸 | 高度 | 左右内边距 | 字号 |
|:----:|:----:|:----------:|:----:|
| 小 | 32px / 64rpx | 12px / 24rpx | 12px |
| 中 | 40px / 80rpx | 16px / 32rpx | 14px |
| 大 | 48px / 96rpx | 24px / 48rpx | 16px |

**规则**：
- 同一页面最多 1 个主按钮
- 主按钮底部固定时，与内容区留 16px 间距
- 点击态：透明度 0.8 或背景色变深

### 3.2 卡片

- 圆角 12px / 24rpx
- 背景白色或 `#F7F7F7`
- 中阴影
- 内边距 16px / 32rpx
- 封面图比例：4:3 或 1:1
- 封面图圆角 8px / 16rpx

### 3.3 输入框

| 状态 | 背景 | 边框 | 说明 |
|------|------|------|------|
| 默认 | 白色 | 1px `#EEEEEE` | - |
| 聚焦 | 白色 | 1px 毛团粉 + 外发光 | `box-shadow: 0 0 0 2px rgba(255,182,193,0.2)` |
| 错误 | 白色 | 1px 错误红 | 下方显示错误文案 |
| 禁用 | `#F7F7F7` | 1px `#EEEEEE` | 不可编辑 |

### 3.4 标签

| 类型 | 背景 | 文字 | 用途 |
|------|------|------|------|
| 普通标签 | `#F7F7F7` | `#666666` | 品种、话题 |
| 会员标签 | 毛团橘 | 白色 | 会员专属 |
| 价格标签 | 毛团粉 | 白色 | 价格、优惠 |
| 状态标签 | 按功能色 | 白色 | 成功/失败/审核中 |

### 3.5 弹窗

| 类型 | 场景 | 按钮规则 |
|------|------|----------|
| 确认弹窗 | 删除、退出 | 左取消（次按钮）+ 右确认（主按钮）|
| 付费弹窗 | 解锁高清 | 大图 + 价格 + 立即支付 |
| 协议弹窗 | 首次进入 | 必须同意，不可关闭 |
| Toast | 成功/失败提示 | 2 秒自动消失 |
| Loading | AI 生成中 | 带进度动画，可取消 |

### 3.6 列表/空状态/错误状态

| 状态 | 视觉 |
|------|------|
| 空状态 | 插画 + 文案 + 操作按钮 |
| 加载中 | 骨架屏或 Loading 动画 |
| 加载失败 | 错误插画 + "点击重试" |
| 无网络 | 断网插画 + "刷新" |
| 无权限 | 锁图标 + "登录/升级会员" |

## 五、页面状态规范

### 5.1 空状态统一模板

```
┌─────────────────┐
│                 │
│    [插画]       │ ← 120×120px
│                 │
│   主文案 16px   │
│   辅助文案 12px │
│                 │
│   [操作按钮]    │
│                 │
└─────────────────┘
```

**示例**：

| 场景 | 插画 | 主文案 | 辅助文案 | 按钮 |
|------|------|--------|----------|------|
| 无宠物档案 | 🐱 | 还没有毛孩子档案 | 创建一个，开始记录吧 | 创建档案 |
| 无作品 | 🖼️ | 还没有作品 | 上传一张照片，生成专属画像 | 去创作 |
| 无订单 | 🧾 | 还没有订单 | 购买会员或单次服务后查看 | 去逛逛 |
| 广场为空 | 🐾 | 还没有内容 | 成为第一个晒毛孩子的人 | 去发布 |

### 5.2 加载状态

| 场景 | 加载方式 | 文案 |
|------|----------|------|
| 页面首次加载 | 骨架屏 | - |
| 下拉刷新 | 顶部 Loading | 下拉刷新 / 释放刷新 |
| 上拉加载 | 底部 Loading | 加载中... |
| AI 生成 | 全屏 Loading + 进度条 | AI 正在创作中，预计 X 秒 |
| 支付中 | 半屏 Loading | 支付处理中... |

### 5.3 错误状态

| 错误 | 文案 | 操作 |
|------|------|------|
| 网络错误 | 网络开小差了 | 点击重试 |
| 服务器错误 | 服务繁忙，请稍后再试 | 点击重试 |
| AI 生成失败 | 生成失败，不扣除额度 | 重新生成 |
| 支付失败 | 支付未完成 | 重新支付 |

## 七、图片与素材规范

### 7.1 上传图片

| 场景 | 建议尺寸 | 格式 | 大小限制 |
|------|---------|------|---------|
| 宠物头像 | 1:1 | JPEG/PNG | ≤ 2MB |
| 画像输入 | 1:1 或 3:4 | JPEG | ≤ 10MB |
| 3D 输入 | 1:1，正面全身 | JPEG | ≤ 5MB |
| 广场发布 | 3:4 或 1:1 | JPEG | 单张 ≤ 5MB，最多 9 张 |

### 7.2 输出图片

| 输出 | 尺寸 | 格式 |
|------|------|------|
| 2D 预览 | 720×720 | JPEG |
| 2D 高清 | 2048×2048 | JPEG |
| 3D 渲染图 | 2048×2048 | PNG |
| 证件卡 | 1080×1350 | PNG |

### 7.3 图标规范

- 线型图标，2px 描边
- 图标尺寸：24×24px（标准），20×20px（小），32×32px（大）
- 颜色：主文字色或毛团粉

## 八、动效规范

| 时长 | 场景 | 缓动 |
|------|------|------|
| 100ms | 按钮点击反馈 | ease-out |
| 150-200ms | 状态切换、标签切换 | ease-out |
| 250ms | 弹窗出现/消失 | ease-in-out |
| 300ms | 页面切换 | ease-in-out |
| 500ms+ | AI 生成进度动画 | linear |

**原则**：
- 动效是为了反馈，不是为了炫技
- 低端机减少动效或关闭
- 页面切换使用原生导航动画

## 九、响应式与适配

- **设计基准**：iPhone 14（390×844）
- **开发单位**：`rpx`（1rpx = 屏幕宽度 / 750）
- **安全区**：
  - 顶部状态栏：44rpx（iOS）/ 由 wx.getSystemInfo 获取
  - 底部安全区：34rpx（iOS 刘海屏）
- **适配规则**：
  - 关键内容在安全区内
  - 底部固定按钮加安全区高度
  - 图片使用 `aspectFill` 或 `aspectFit` 避免变形

详见 [`docs/设计/品牌与文案规范.md`](品牌与文案规范.md)。
