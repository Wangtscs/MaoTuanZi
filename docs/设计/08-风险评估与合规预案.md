## 一、风险评估方法

```
        │ 影响小 │ 影响中 │ 影响大 │
────────┼───────┼───────┼───────┤
概率高  │  🟡   │  🟠   │  🔴   │
概率中  │  🟢   │  🟡   │  🟠   │

| 等级 | 标识 | 响应时间 | 处置 |

| 🔴 严重 | P0 | 即时（< 30 min）| 全员响应 |

| 🟡 中 | P2 | < 24 小时 | 当事人 |

## 三、合规预案

### 3.1 医疗内容合规

**红线**：

| ❌ 禁止 | ✅ 允许 |
|---------|---------|
| 任何疾病诊断结论 | 通用居家护理常识 |
| 药品推荐 / 剂量指导 | 喂养建议（基于档案） |
| 治疗方案 / 手术建议 | 风险提示 + 就医指引 |
| 替代兽医诊断的暗示 | 免责声明置顶 |

**机制（多层防护）**：

```
Layer 1：Prompt 工程约束
    ↓
Layer 2：内容安全 API 过滤
    ↓
Layer 3：UI 层免责声明置顶
    ↓
Layer 4：用户教育（首次使用弹窗）
    ↓
Layer 5：月度抽检（人工 100 条）
    ↓
Layer 6：应急下线（发现问题立即处理）
```

### 3.2 AI 生成内容合规

**审核链路**：

```
用户输入 → Prompt 约束 → AI 生成 → 内容安全 API
                              ↓
                          机审通过 → 展示
                          机审失败 → 不展示 + 自动重试（不扣额度）
                              ↓ 3 次仍失败
                          转人工 → 仍失败 → 永久拦截 + 通知
```

**审核维度**：
- 政治敏感
- 色情低俗
- 暴恐血腥
- 未成年人
- 歧视辱骂
- 版权侵权

### 3.3 数据隐私合规

**采集最小化**：

- 仅收集服务必需字段
- 敏感字段单独授权（过敏史、症状）
- 设备 ID 匿名化

**存储加密**：

- 密码 / Token 不入库
- 过敏史 AES-256 加密
- 数据库连接 SSL

**用户权利**（路径）：

| 权利 | 路径 | 响应时间 |
|------|------|---------|
| 查阅 | 个人中心 → 各模块 | 即时 |
| 更正 | 个人中心 → 编辑 | 即时 |
| 删除 | 个人中心 → 删除 / 设置 → 注销 | 即时 |
| 注销 | 设置 → 账号注销 | 15 个工作日 |
| 导出 | 设置 → 数据导出 | 15 个工作日 |

**第三方共享清单**（公开）：

| 服务商 | 数据类型 | 用途 |
|-------|---------|------|
| 微信支付 | 订单信息 | 支付 |
| 微信开放平台 | OpenID | 登录 |
| AI 服务商 | 上传图片 + 任务参数 | 生成 |
| 内容安全 | 用户发布内容 | 审核 |

### 3.4 微信小程序合规

**类目选择建议**：

| 类目 | 风险 | 建议 |
|------|------|------|
| 工具 → 效率 | 低 | ✅ 主选 |
| 工具 → 图像处理 | 低 | ✅ 备选 |
| 宠物服务 | 中 | ⚠️ 需资质 |
| 宠物医疗 | 高 | ❌ 不建议 |

**订阅消息**：

- 仅用一次性订阅（用户主动触发）
- 不申请长期订阅
- 提供关闭入口

## 四、应急响应流程

### 4.1 响应小组（最小配置）

| 角色 | 人员 | 职责 |
|------|------|------|
| 总指挥 | 创始人 / 产品负责人 | 决策、对外沟通 |
| 技术 | 后端 / 运维 | 故障排查、修复 |
| 产品 | 产品负责人 | 用户沟通、功能调整 |
| 客服 | 客服主管 | 用户咨询、投诉处理 |

### 4.2 P0 响应流程

```
T+0  故障发现（监控告警 / 用户反馈）
T+5  响应启动（拉群）
T+15 故障定位 + 影响评估
T+30 决策（修复 / 降级 / 公告）
T+X  执行（修复 / 公告 / 通知）
T+24h 复盘（输出报告）
```

### 4.3 公告模板

**模板 A：紧急维护**

```
【毛团子AI 紧急维护通知】

亲爱的毛团子用户：
我们正在紧急处理 [功能] 异常，预计 [时间] 恢复。
受影响的用户可申请 [补偿方案]。
对此造成的不便，我们深表歉意。

客服微信：xxx
```

**模板 B：数据安全事件**

```
【毛团子AI 安全公告】

亲爱的毛团子用户：
我们于 [时间] 发现 [事件]，已立即采取措施：
1. xxx
2. xxx
3. xxx

建议用户 [立即修改密码 / 检查账户 / 其他行动]。
如有疑问，请联系客服。

毛团子AI 团队
