# 毛团子AI · 状态机与业务规则汇总

**版本**：V1.0 | **更新**：2026-08-18

> 业务规则分散在 [`prd2.md`](../../prd2.md) 和 [`/docs/设计/05-数据库设计文档.md`](05-数据库设计文档.md)。本文档集中定义**所有状态机 + 关键业务规则**，作为后端实现的唯一参考。

## 一、AI 任务状态机

```
              pending(0)
                ↓ 入队
              pending(0) ── 取消 ──> cancelled(4)
                ↓ Worker 调度
            processing(1) ── 取消 ──> cancelled(4)
                ↓
        ┌───────┼───────┐
        ↓       ↓       ↓
    success(2) failed(3) failed(3)
        ↓       ↓       ↓
       [终]   retry≤3   [终]
                ↓
            pending(0)
```

### 规则

| 规则 | 说明 |
|------|------|
| 初始状态 | pending |
| 终态 | success / failed（重试耗尽）/ cancelled |
| 重试上限 | 3 次 |
| 取消权限 | pending / processing 可取消；success / failed 不可取消 |
| 失败不扣费 | failed 状态不扣额度（按 PRD §3.2.4） |

### 数据库字段：`ai_tasks.status`

```sql
status TINYINT NOT NULL DEFAULT 0
-- 0=pending 1=processing 2=success 3=failed 4=cancelled
```

## 二、作品状态机

```
   生成中（status=0）
        ↓
   预览态（preview_url 生成）
        ↓ 用户付费 / 会员
   完成态（result_url 解锁）
        ↓ 发布广场
   公开态（is_public=1）
        ↓ 用户删除
   已删态（status=3, deleted_at!=null）
        ↓ 30 天
   [物理删除]
```

### 规则

| 规则 | 说明 |
|------|------|
| `result_url` | 仅付费 / 会员可见，**服务端二次鉴权** |
| 软删除 | `status=3` + `deleted_at=now()`，30 天后硬删 |
| 删除级联 | 删除宠物时级联删除该宠物作品 |
| 退款触发 | 24h 内退款成功后作品保留，但 `is_public=false` |

## 三、订单状态机

```
   待支付(0)
      ↓ 微信回调
   已支付(1) ── 退款申请 ──> 退款中(4)
      ↓                     ↓
   已完成(2)             已退款(2*)/拒绝退款
      ↓
   [终]
   待支付(0) ── 超时 ──> 已关闭(3)
                  取消
                  [终]
```

### 规则

| 状态 | 含义 | 触发动作 |
|------|------|---------|
| 0 待支付 | 订单创建未支付 | 30 分钟超时关闭 |
| 1 已支付 | 微信支付回调成功 | 发放权益 |
| 2 已完成 | 订单已完成（默认）| - |
| 3 已关闭 | 超时 / 用户取消 | - |
| 4 退款中 | 申请退款后 | 审核（≤24h）|
| 5 已退款 | 退款成功 | - |
| 6 拒绝退款 | 审核不通过 | - |

### 关键不变量

- `paid_at` 一旦设置不可修改
- 退款成功后 `orders.status=2`（已支付）→ 标记 `refunded_at`
- 订单金额 `pay_amount_cents` 一旦确定不可修改

## 四、退款状态机

```
   待审核(0) ── 审核通过 ──> 退款中(1)
      ↓
   审核拒绝(2)
      ↓
   [终]

   退款中(1) ── 微信回调 ──> 已退款(3)
                       ↓
                      [终]
```

### 退款规则（与 `/docs/合规法律/21-用户服务协议.md` §4.4 对齐）

| 商品 | 可退 | 限制 |
|------|:---:|------|
| 2D 画像 | ✅ | 24h 内、未分享、未使用 |
| 3D 手办 | ✅ | 24h 内、未导出 |
| 喂养方案 | ❌ | 已交付内容 |
| 会员 | ❌ | - |
| 套餐 | ❌ | - |
| 表情包 / 证件卡 | ❌ | - |
| 3D 打印文件 | ❌ | - |

**每月退款次数限制**：≤1 次 / 商品类型

## 五、会员状态机

```
   ┌─> 普通用户(0)
   │       ↓ 购买月卡
   ├─> 月卡会员(1) ── 到期 ──> 普通用户(0)
   │       ↓ 续费
   ├─> 季卡会员(2) ── 到期 ──> 普通用户(0)
   │       ↓ 续费
   ├─> 年卡会员(3) ── 到期 ──> 普通用户(0)
   │
   用户封禁(1) ──> 状态=status=1（不影响 vip_level）
```

### 规则

| 规则 | 说明 |
|------|------|
| 升级 | 月→季、年卡可叠加到期时间 |
| 降级 | 不自动降级，用户主动不续费 |
| 续费 | 在到期前 7/3/1 天推送提醒 |
| 退款 | 会员生效后不支持退款 |
| 额度重置 | 自然月重置（如 9 月 1 日重置 9 月额度）|

### 数据库字段

- `users.vip_level`（0/1/2/3）
- `users.vip_expire_at`
- `vip_records` 流水表记录所有变更

## 六、广场帖子状态机

```
   草稿(用户本地)
      ↓ 发布
   审核中(0) ── 机审拦截 ──> 已下架(2) [立即通知用户]
      ↓
   已发布(1)
      ↓ 举报 + 人工审核通过
   已下架(2)
      ↓ 用户删除
   已删除(3) [30 天物理删除]
```

### 内容审核规则

| 维度 | 触发 |
|------|------|
| 政治敏感 | 机审（关键词 + AI 分类）|
| 色情低俗 | 机审 |
| 暴恐血腥 | 机审 |
| 非自家宠物 | 抽检（人工） |
| 商业广告 | 抽检 |
| 版权侵权 | 用户举报 → 人工 |

## 七、健康提醒状态机

```
   已创建(is_active=1)
      ↓ 周期到期
   待触发(next_run_at <= now())
      ↓ 触发
   触发中(推送中)
      ↓ 推送完成
   已触发(更新 next_run_at)
      ↓ 用户关闭
   已停用(is_active=0)
```

### 规则

- 单次提醒：触发后 `cycle_days=null`，不重复
- 周期提醒：触发后 `next_run_at += cycle_days`
- 免费用户：≤3 条；会员：无限

## 八、关键业务规则

### 8.1 用户注册

- 一个微信账号绑定一个毛团子账号
- 首次注册 = 新用户（首单优惠）
- 注销后 30 天硬删数据

### 8.2 宠物档案

- 宠物头像必须先上传到 OSS
- 免费用户最多 2 只宠物
- 删除宠物 = 级联删除该宠物所有作品 + 记录

### 8.3 AI 任务

- 创建前检查用户额度
- 创建后立即返回 `task_id`，客户端轮询
- 任务失败不扣额度
- preview_url 有效期 24h（超过需重新生成）
- result_url 仅付费 / 会员可见

### 8.4 支付

- 单订单单次创建，不可重复
- 微信支付回调是**唯一可靠**的支付成功标志（不要靠前端回调）
- 支付成功后**幂等发放权益**（用 `wx_transaction_id` 去重）

### 8.5 退款

- 退款金额 ≤ 原订单实付金额
- 退款成功后撤销权益（会员降级、扣减额度）
- 微信退款异步通知（≤ 1-3 工作日到账）

### 8.6 广场

- 仅点赞，无评论、无私信
- 同一用户对同一帖子只能点赞 1 次
- 用户每天打招呼 ≤ 3 次
