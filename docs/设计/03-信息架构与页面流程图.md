**版本**：V2.0 | **更新日期**：2026-08-18 | **关联 PRD**：V2.0

## 一、整体信息架构

### 1.1 顶层结构（5 个 Tab）

```
毛团子AI（微信小程序）
│
├── 🔵 首页 Tab
├── 🟣 AI 创作 Tab
├── 🟢 工具 Tab
├── 🟡 萌宠广场 Tab
└── 🔴 我的 Tab
```

### 1.2 每个 Tab 包含什么

| Tab | 核心职责 | 内部组织方式 |
|-----|---------|------------|
| 首页 | 工具聚合 + 内容推荐 | 顶部 Banner + 工具宫格 + 推荐流 + 会员入口 |
| AI 创作 | 所有 AI 功能的入口 | 顶部 Tab（2D / 3D / 表情包 / 卡片 / 文案）|
| 工具 | 日常养宠工具 | 左分类右列表 / 全部展开 |
| 广场 | 内容浏览与发布 | 顶部 Tab（最新 / 最热 / 3D专区 / 挑战）|
| 我的 | 个人中心 | 列表式 |

### 1.3 页面编号规则

```
P-{模块}{序号}
模块：H(Home) / A(AI) / T(Tool) / S(Square) / M(Me) / L(Legal) / O(Onboarding)
```

## 四、核心用户路径流程图

### 4.1 颜值付费路径（2D 画像）

```
[任意入口]
    │ 首页 Banner / AI 创作 Tab / 我的
    ▼
[P-A02 上传图片]
    │ 未选宠物：引导选择/创建
    │ 选择已有宠物照片 OR 上传新图
    ▼
[P-A03 选择风格]
    │ 免费 1-2 款 vs 会员 8+ 款
    │ 会员专属显示锁标 + 价格
    ▼
[提交 /v1/ai/tasks]
    │ 客户端轮询 /v1/ai/tasks/{id}
    ▼
[P-A04 生成预览]
    │ status: pending → processing → success
    │ 进度条 + 提示文案
    ▼
[预览展示 + 即时付费弹窗]
    │ 弹窗触发：成功后 1.5s
    │ 用户操作：立即解锁 / 关闭 / 分享后再来
    │ 关闭后：仍可查看预览，付费入口置底
    ▼
[付费 / 会员扣额度]
    │ 调 /v1/orders 创建订单
    │ 调 wx.requestPayment
    │ 调 /v1/webhooks/wx-pay 后端更新订单
    ▼
[P-A05 高清成品]
    │ 解锁 result_url
    │ 操作：保存相册 / 分享 / 发布到广场 / 同款再来
    ▼
[完成 → 我的作品]
```

**关键节点说明**：
- 上传页引导：宠物档案为空时，强引导创建（不阻塞，可跳过）
- 风格选择：会员专属风格清晰标识，但**不阻塞免费体验**
- 预览页：付费弹窗可在 5 秒后手动关闭，**不强制**
- 付费后：自动跳转作品详情，引导保存分享

### 4.2 3D 手办路径

```
[任意入口]
    ▼
[P-A06 选择模式]
    │ 快速单图（免费 1 次/日）
    │ 高精度多图（付费）
    ▼
[P-A07 上传图片]
    │ 拍照引导：正面全身、光线充足、无遮挡
    │ 1 张 / 3 张
    ▼
[提交 /v1/ai/tasks]
    │ 异步任务
    ▼
[P-A08 生成中]
    │ 通常 30s - 3min
    │ 可后台，用户继续其他操作
    │ 任务完成推送订阅消息
    ▼
[P-A09 3D 交互]
    │ 旋转 / 缩放 / 材质 / 背景 / 动作
    │ 免费用户：低面数 + 部分材质限制
    │ 体验 15 秒弹付费窗（可关闭）
    ▼
[付费解锁]
    │ 高精度模型 + 全部材质
    │ 加购 STL 文件（+20 元）
    ▼
[P-A10 高清导出]
    │ 4K 渲染图 × 4
    │ 旋转视频 10s
    ▼
[保存 / 分享 / 发布到 3D 专区]
```

### 4.3 工具付费路径（喂养方案）

```
[工具 Tab / 症状查询结果页]
    ▼
[P-T10 喂养方案生成]
    │ 选择宠物
    │ 补充喂养细节
    ▼
[预览大纲（脱敏）]
    │ 显示方案结构 + 价格
    ▼
[付费 19.9 元 / 会员无限]
    ▼
[生成完整方案]
    │ 调用 AI 网关
    │ 异步任务 /v1/ai/tasks type=feeding_plan
    ▼
[方案详情页]
    │ 完整内容
    │ 操作：导出长图 / 调整（≤3 次）
    ▼
[保存到宠物档案 / 提醒联动]
```

### 4.4 留存路径（提醒 + 广场）

```
[订阅消息推送]
    │ 提醒类型：疫苗 / 驱虫 / 生日
    ▼
[点击推送 → 进入对应页面]
    ├─ 疫苗提醒 → P-T05 + 同款喂养方案推荐
    ├─ 驱虫提醒 → 同上
    └─ 生日提醒 → P-A12 纪念卡 + P-A06 3D 手办
[完成打卡 → 获取积分 / 券]
    ▼
[P-S01 广场浏览]
    ▼
[点赞 / 同款跳转]
```

### 4.5 社交引流路径

```
[P-S01 广场浏览]
    ▼
[P-S02 帖子详情]
    │ 看到喜欢的画像 / 3D
    ▼
[点击同款跳转]
    │ 携带 style / template 参数
    ▼
[P-A02 / P-A07]
    │ 直接进入对应生成页
    │ style 已预选
    ▼
[体验 → 付费转化]
```

### 4.6 首次访问路径

```
[首次打开小程序]
    ▼
[P-O01 隐私协议弹窗]
    │ 强制同意
    │ 不同意 → 关闭小程序
    ▼
[P-O02 用户协议弹窗]
    │ 强制同意
    ▼
[首页 P-H01]
    │ 游客模式：可使用免费功能
    │ 引导创建宠物档案（不强求）
    ▼
[触发付费 → 微信登录]
    │ 调 /v1/auth/wx-login
    │ 同步历史作品（若有）
    ▼
```

### 4.7 注销账号路径

```
[P-M09 设置]
    ▼
[点击注销账号]
    │ 显示注销须知（不可恢复、会员权益失效）
    ▼
[二次确认]
    │ 输入验证码 / 滑块
    ▼
[调 /v1/users/me/cancel]
    │ status=2, deleted_at=now()
    ▼
[15 天后定时任务硬删]
    │ 期间用户可登录撤销
    ▼
[已注销]
```

## 五、关键状态流转

### 5.1 用户态

```
游客态
    │ 微信登录
    ▼
注册态（普通）
    │ 首次付费
    ▼
付费态
    │ 订阅会员
    ▼
会员态（月 / 季 / 年）
    │ 到期未续
    ▼
流失态
    │ 召回成功
    ▼
会员态
    │ 注销
    ▼
注销态（15 天后硬删）
```

### 5.2 AI 任务态（与设计-05 / 设计-06 一致）

```
pending（待处理）
    │ Worker 调度
    ▼
processing（处理中）
    │ 成功
    ▼
success（成功）── 终态
    │ 失败可重试
    ▼
failed（失败）
    │ 重试 ≤ 3 次 → pending
    │ 超过 → 终态
    ▼
[失败终态]

任意状态 → cancelled（用户取消）
```

### 5.3 作品态

```
生成中 → 预览态（低清）
    │ 付费 / 会员
    ▼
完成态（高清）
    │ 发布广场
    ▼
公开态
    │ 删除
    ▼
已删态（30 天后清理）
```

### 5.4 订单态

```
待支付
    │ 支付成功 → 已支付 → 已完成
    │ 取消 → 已关闭
    │ 退款 → 退款中 → 已退款 / 拒绝
    │ 超时 → 已关闭（自动）
```

### 5.5 提醒态

```
已创建 → 待触发 → 触发中 → 已触发
                    │
                    └─ 周期提醒：触发后更新 next_run_at
```

## 七、异常与边界路径

### 7.1 网络异常

| 场景 | 处理 |
|------|------|
| AI 生成中断网 | 本地缓存 task_id，恢复后自动续 |
| 列表加载失败 | 骨架屏 + 重试按钮 |
| 上传失败 | 提示 + 重试（保留本地选择） |

### 7.2 权限缺失

| 场景 | 处理 |
|------|------|
| 未授权相册 | 提示并引导授权 |
| 拒绝授权 | 显示功能不可用 + 再次授权入口 |

### 7.3 付费边界

| 场景 | 处理 |
|------|------|
| 游客点击付费 | 强制弹微信登录 |
| 会员到期 | 生成中可继续完成，已生成作品仍可查看 |
| 余额不足 | 引导开通会员 |

### 7.4 内容违规

| 场景 | 处理 |
|------|------|
| 广场发布机审拦截 | 提示 + 不消耗额度 |
| AI 输出违规 | 不展示 + 自动重试 |
| 头像违规 | 人工抽检下架 + 通知 |

## 八、Tab Bar 与导航策略

### 8.1 一级导航（Tab Bar）

- 5 个固定 Tab，不可增减
- 中间 Tab 可点击外层区域激活

### 8.2 二级导航

- **AI 创作 Tab**：顶部横向 Tab 切换分类
- **工具 Tab**：左分类导航 + 右功能区
- **广场 Tab**：顶部 Tab 切换

### 8.3 三级导航

- 每个二级页面用页面内返回（不新开 Tab）
- 长流程任务用 Page Stack（可返回中断页）
