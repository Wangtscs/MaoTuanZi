# 毛团子AI · 数据库设计文档

**版本**：V2.0 | **更新日期**：2026-08-18 | **关联 PRD**：V2.0

> 本文档定义毛团子AI 的核心实体关系与表结构。**表结构变更必须先更新本文档**，走评审后再执行迁移。

---

## 一、设计原则

| 原则 | 含义 |
|------|------|
| 单库起步 | MVP 单库，不分库 |
| 软删除统一 | 用 `deleted_at`（DATETIME）字段，**禁止混用 `is_deleted`** |
| 时间字段统一 | `created_at`、`updated_at`（DATETIME，秒级精度足够）|
| 主键统一 | `id BIGINT UNSIGNED AUTO_INCREMENT` |
| 索引命名规范 | `idx_xxx` 普通、`uk_xxx` 唯一 |
| JSON 字段节制 | 仅用于真正灵活的字段，**必须有结构示例** |
| 外键策略 | **应用层维护一致性**（MySQL 外键影响性能） |

## 三、表结构

> 篇幅所限，列出**核心表**，辅助表（如字典表）简略描述。

### 3.1 `users` 用户表

```sql
CREATE TABLE users (
    id              BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT COMMENT '主键',
    openid          VARCHAR(64)  NOT NULL COMMENT '微信 OpenID',
    unionid         VARCHAR(64)      NULL COMMENT '微信 UnionID（多端打通）',
    nickname        VARCHAR(64)      NULL COMMENT '微信昵称',
    avatar_url      VARCHAR(512)     NULL COMMENT '微信头像 URL',
    phone           VARCHAR(20)      NULL COMMENT '手机号（脱敏存储）',
    status          TINYINT      NOT NULL DEFAULT 0 COMMENT '0=正常 1=封禁 2=注销',
    vip_level       TINYINT      NOT NULL DEFAULT 0 COMMENT '0=无 1=月 2=季 3=年',
    vip_expire_at   DATETIME         NULL COMMENT '会员到期时间',
    register_source VARCHAR(32)      NULL COMMENT '注册来源（share/direct/ad）',
    last_login_at   DATETIME         NULL COMMENT '最后登录时间',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at      DATETIME         NULL COMMENT '软删除时间',

    UNIQUE KEY uk_openid (openid),
    KEY idx_vip_expire (vip_expire_at, vip_level),
    KEY idx_status_created (status, created_at),
    KEY idx_deleted (deleted_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT '用户表';
```

**业务规则**（应用层校验）：
- 一个用户最多 N 只宠物（免费 N=2，会员不限制）
- 注销账号 15 天后硬删除（GDPR/个保法要求）

### 3.2 `pets` 宠物档案表

```sql
CREATE TABLE pets (
    id           BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    user_id      BIGINT UNSIGNED NOT NULL COMMENT '所属用户',
    nickname     VARCHAR(64)  NOT NULL COMMENT '宠物昵称',
    species      TINYINT      NOT NULL COMMENT '1=猫 2=犬 3=其他',
    breed_id     INT              NULL COMMENT '品种 ID（关联 breeds.id）',

    gender       TINYINT      NOT NULL DEFAULT 0 COMMENT '0=未知 1=公 2=母',
    birthday     DATE             NULL COMMENT '出生日期',
    weight_kg    DECIMAL(5,2)     NULL COMMENT '体重 kg（精度 0.01）',
    is_neutered  TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '是否绝育',
    allergies    JSON             NULL COMMENT '过敏史（结构见下）',
    staple_food  VARCHAR(128)     NULL COMMENT '主食品牌',
    avatar_url   VARCHAR(512)     NULL COMMENT '宠物头像',
```

### 3.4 `works` 作品表

```sql
CREATE TABLE works (
    id           BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    user_id      BIGINT UNSIGNED NOT NULL,
    pet_id       BIGINT UNSIGNED     NULL COMMENT '关联宠物（可空）',
    type         TINYINT      NOT NULL COMMENT '1=2D画像 2=3D 3=表情包 4=证件卡 5=文案',
    style        VARCHAR(32)      NULL COMMENT '风格 / 模板标识',
    status       TINYINT      NOT NULL DEFAULT 0 COMMENT '0=生成中 1=成功 2=失败 3=已删除',
    preview_url  VARCHAR(512)     NULL COMMENT '低清预览 URL',
    result_url   VARCHAR(512)     NULL COMMENT '高清成品 URL（付费后）',
    extra_urls   JSON             NULL COMMENT '多角度/视频/STL（结构见下）',
    is_public    TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '是否发布到广场',
    publish_at   DATETIME         NULL COMMENT '发布时间',
    like_count   INT          NOT NULL DEFAULT 0,
    cost_cents   INT          NOT NULL DEFAULT 0 COMMENT 'AI 成本（分）',
    created_at   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at   DATETIME         NULL,

    KEY idx_user_type_status (user_id, type, status, deleted_at),
    KEY idx_user_public (user_id, is_public, deleted_at, created_at),
    KEY idx_pet (pet_id),
    KEY idx_published (is_public, status, deleted_at, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT '作品表';
```

**`extra_urls` JSON 结构（按 type 不同）**：

```json
{
    "hd_images": ["url1", "url2", "url3", "url4"],
    "video_url": "...",
    "stl_url": "...",
    "thumbnail": "..."
}
```

**业务规则**：
- `result_url` 仅付费或会员可见，否则返回 `preview_url`
- 用户删除作品 → `status=3` + `deleted_at=now()`（保留 30 天后硬删）

### 3.5 `ai_tasks` AI 任务表

```sql
CREATE TABLE ai_tasks (
    id              BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT UNSIGNED NOT NULL,
    work_id         BIGINT UNSIGNED     NULL COMMENT '关联作品',
    type            VARCHAR(32)  NOT NULL COMMENT '任务类型',
    status          TINYINT      NOT NULL DEFAULT 0 COMMENT '0=pending 1=processing 2=success 3=failed 4=cancelled',
    provider        VARCHAR(32)      NULL COMMENT '使用的服务商',
    request_payload JSON             NULL COMMENT '请求参数（脱敏）',
    response_payload JSON            NULL COMMENT '响应结果（脱敏）',
    error_code      VARCHAR(32)      NULL,
    error_msg       VARCHAR(512)     NULL,
    cost_cents      INT          NOT NULL DEFAULT 0,
    retry_count     TINYINT      NOT NULL DEFAULT 0,
    started_at      DATETIME         NULL,
    finished_at     DATETIME         NULL,
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    KEY idx_user_status (user_id, status, created_at),
    KEY idx_work (work_id),
    KEY idx_status_created (status, created_at),
    KEY idx_type_provider (type, provider, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT 'AI 任务表';
```

**状态流转**（与设计-04 §6.1 对齐）：

```
pending → processing → success
                ↓
              failed → pending (retry ≤ 3)
                ↓
              failed (重试耗尽)
任意状态 → cancelled
```

### 3.6 `orders` 订单表

```sql
CREATE TABLE orders (
    id                  BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    order_no            VARCHAR(32)  NOT NULL COMMENT '业务订单号',
    user_id             BIGINT UNSIGNED NOT NULL,
    product_type        TINYINT      NOT NULL COMMENT '1=单次 2=套餐 3=会员',
    product_id          VARCHAR(32)  NOT NULL COMMENT '商品标识',
    product_name        VARCHAR(64)  NOT NULL,
    amount_cents        INT          NOT NULL COMMENT '应付金额（分）',
    pay_amount_cents    INT          NOT NULL COMMENT '实付金额（分）',
    discount_cents      INT          NOT NULL DEFAULT 0,
    coupon_id           BIGINT UNSIGNED NULL,
    status              TINYINT      NOT NULL DEFAULT 0 COMMENT '0=待支付 1=已支付 2=已退款 3=已关闭 4=退款中',
    pay_method          VARCHAR(16)      NULL,
    wx_transaction_id   VARCHAR(64)      NULL,
    paid_at             DATETIME         NULL,
    closed_at           DATETIME         NULL,
    refunded_at         DATETIME         NULL,
    expire_at           DATETIME         NULL COMMENT '待支付过期时间',
    created_at          DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at          DATETIME         NULL,

    UNIQUE KEY uk_order_no (order_no),
    KEY idx_user_status (user_id, status, created_at),
    KEY idx_wx_txn (wx_transaction_id),
    KEY idx_paid_at (paid_at),
    KEY idx_status_expire (status, expire_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT '订单表';
```

**订单号规则**：`MT` + yyyyMMddHHmmss + 6 位随机数

**关键索引说明**：
- `idx_status_expire`：用于定时任务扫描超时未支付订单
- `idx_user_status`：用户查看我的订单
- `idx_paid_at`：日报统计

### 3.9 `coupons` 优惠券 + `coupon_claims` 领取记录

```sql
CREATE TABLE coupons (
    id                   BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    code                 VARCHAR(32)  NOT NULL COMMENT '券码',
    type                 TINYINT      NOT NULL COMMENT '1=满减 2=折扣 3=兑换券',
    name                 VARCHAR(64)  NOT NULL,
    discount_cents       INT              NULL COMMENT '满减金额（分）',
    discount_rate        DECIMAL(3,2)     NULL COMMENT '折扣率（0.00-1.00）',
    min_amount_cents     INT              NULL COMMENT '最低使用金额',
    applicable_products  JSON             NULL COMMENT '适用商品列表',
    valid_start          DATETIME     NOT NULL,
    valid_end            DATETIME     NOT NULL,
    total_count          INT          NOT NULL COMMENT '总发行量',
    claimed_count        INT          NOT NULL DEFAULT 0 COMMENT '已领取量',
    per_user_limit       INT          NOT NULL DEFAULT 1,
    status               TINYINT      NOT NULL DEFAULT 1 COMMENT '1=启用 0=禁用',
    created_at           DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at           DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_code (code),
    KEY idx_validity (valid_start, valid_end, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT '优惠券表';

CREATE TABLE coupon_claims (
    id              BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    coupon_id       BIGINT UNSIGNED NOT NULL,
    user_id         BIGINT UNSIGNED NOT NULL,
    order_id        BIGINT UNSIGNED     NULL,
    status          TINYINT      NOT NULL DEFAULT 0 COMMENT '0=未用 1=已用 2=过期',
    used_at         DATETIME         NULL,
    expire_at       DATETIME     NOT NULL,
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_coupon_user (coupon_id, user_id),
    KEY idx_user_status (user_id, status, expire_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='优惠券领取记录';
```

**并发领取**：使用 `UPDATE coupons SET claimed_count = claimed_count + 1 WHERE id = ? AND claimed_count < total_count` 行锁保证。

### 3.14 `square_posts` 广场帖子 + `post_likes` 点赞

```sql

    KEY idx_topic (topic, status, created_at),
    KEY idx_likes (like_count, status, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='广场帖子';

CREATE TABLE post_likes (
    post_id         BIGINT UNSIGNED NOT NULL,
    user_id         BIGINT UNSIGNED NOT NULL,
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (post_id, user_id),
```

**点赞一致性**：`like_count` 是冗余字段（性能考虑），用 `UPDATE ... SET like_count = (SELECT COUNT(*) FROM post_likes WHERE post_id=?)` 定期校对，或在事务中同步更新。

## 四、Redis 缓存 Key 设计

### 4.1 会话与权限

```
session:{openid}            → 用户会话（hash）
token:invalid:{jwt}           → JWT 黑名单
wx:access_token              → 微信接口调用凭证（TTL 110min）
```

### 4.2 业务快照

```
user:{user_id}:profile       → 用户基本信息（hash，TTL 1h）
user:{user_id}:vip           → 会员快照（hash，TTL 30min）
user:{user_id}:quota         → 额度快照（hash，TTL 5min）
```

### 4.3 额度与限流

```
quota:{user_id}:portrait     → 画像剩余次数（int，TTL 1d）
quota:{user_id}:3d           → 3D 剩余次数（int，TTL 1d）
rl:{user_id}:{action}        → 限流计数（int，TTL 60s/1d）
task:user:{user_id}:running  → 用户并发任务数（int，TTL 5min）
task:global:running          → 全局并发任务数（int）
```

### 4.4 静态数据

```
breeds:{species}             → 品种列表（list，TTL 24h）
templates:{type}             → 模板列表（list，TTL 1h）
styles:{type}                → 风格列表（list，TTL 1h）
```

### 4.5 幂等与锁

```
idempotent:{key}            → 幂等结果（TTL 24h）
lock:{resource}              → 分布式锁（TTL 任务时长）
```

## 五、对象存储结构

```
oss://maotuanzi-prod/
├── uploads/                       # 用户上传原图

│   ├── 3d/{yyyy}/{mm}/{dd}/{work_id}.glb          # 3D 模型
│   ├── 3d/{yyyy}/{mm}/{dd}/{work_id}.stl          # 3D 打印
│   └── video/{yyyy}/{mm}/{dd}/{work_id}.mp4       # 视频
├── square/                        # 广场公开（CDN）
│   └── {yyyy}/{mm}/{dd}/{post_id}/{idx}.jpg
├── static/                        # 静态资源
│   ├── breeds/{breed_id}.jpg
│   ├── templates/{template_id}.jpg

    └── {yyyy}/{mm}/{dd}/{uuid}
```

**访问策略**：
- `uploads/`, `works/` 私有读 + 签名 URL（24h）
- `square/`, `static/` 公共读 + CDN 缓存
- `temp/` 私有读，定期清理

## 九、迁移规范

### 9.1 工具

- **开发**：TypeORM migrations / Prisma migrate
- **生产执行**：`npm run db:migrate:prod`（带二次确认）

### 9.2 规范

- 每个迁移必须有 `up` 和 `down`
- 大表变更（如加索引）用 `pt-online-schema-change`
- 删字段前先确保无业务依赖

### 9.3 审核

- DDL 变更需 Code Review
- 大表 DDL 需 DBA / 技术负责人批准
- 重要变更需备份后再执行
