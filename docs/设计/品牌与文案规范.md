# 毛团子AI · 品牌与文案规范

**版本**：V1.0 | **更新**：2026-08-18

> 毛团子AI 是**情感型**产品，文案要传递温度。

---

## 一、品牌定位

| 维度 | 描述 |
|------|------|
| 名称 | 毛团子AI |
| 一句话 | 用 AI 让每一只毛孩子被温柔以待 |
| 调性 | 温暖、治愈、像朋友 |
| 用户感知 | "这是我毛孩子的专属摄影师" |

## 二、语气

### 2.1 推荐

- ✅ "太好看啦！解锁高清无水印版～"
- ✅ "试试给毛孩子做个画像吧"
- ✅ "你家团子今天想拍什么风格？"
- ✅ "我们一起守护毛孩子的健康"

### 2.2 禁用

- ❌ 命令式："立即购买！"
- ❌ 恐吓式："再不买就亏了"
- ❌ 低俗："绝对震惊的效果"
- ❌ 医疗夸大："100% 治愈"

## 三、文案风格

### 3.1 称呼

| 对象 | 称呼 |
|------|------|
| 用户 | "你" |
| 宠物 | "毛孩子" / "[宠物昵称]" |
| 多只宠物 | "毛孩子们" |

### 3.2 标点

- ✅ 用 "～"、"🐾" 等表达情感
- ✅ 句末用 "。"（正式）或 "～"（亲切）
- ❌ 不要用 "!"、"？" 表达命令感

### 3.3 数字

| 类型 | 写法 |
|------|------|
| 价格 | `¥9.9` / `¥19.9` |
| 时间 | `2 分钟前` / `刚刚` |
| 数量 | `1,234`（千分位）|

## 四、按钮文案

| 场景 | 文案 |
|------|------|
| 主要操作 | "解锁高清"、"立即生成"、"保存相册" |
| 次要操作 | "再试一次"、"换个风格" |
| 危险操作 | "删除"、"取消关注" |
| 完成 | "已完成"、"已保存" |

## 五、空状态文案

| 场景 | 文案 |
|------|------|
| 无宠物 | "还没有毛孩子的档案，去创建一个吧" |
| 无作品 | "毛孩子的第一张画像等着你哦" |
| 无订单 | "还没有订单哦" |
| 搜索无结果 | "换个关键词试试" |
| 加载失败 | "加载失败，下拉重试" |

## 六、错误文案

| 错误 | 文案 |
|------|------|
| 网络错误 | "网络好像不太给力，稍后再试" |
| 服务异常 | "服务暂时不可用，请稍后" |
| 权限不足 | "需要登录才能使用这个功能" |
| 余额不足 | "本月次数已用完，升级会员解锁更多" |

## 七、推送文案（订阅消息）

| 场景 | 文案 |
|------|------|
| 健康提醒 | "[宠物名]的[类型]提醒：今天记得..." |
| AI 完成 | "[宠物名]的画像已完成，点击查看" |
| 会员到期 | 您的会员将于 X 天后到期，续费享... |
| 活动 | 限时活动：3 张画像仅需 ¥9.9 |

## 八、社交文案（广场）

- ✅ 友好、分享宠物日常
- ✅ 提问、寻求建议
- ❌ 商业广告
- ❌ 引流到外部
- ❌ 不实宣传

## 九、专题与活动文案

模板：

```
【[活动名]】

[一句话痛点]
[一句话方案]
[用户收益]

活动详情：[URL]
```

## 十、禁用词

| 类别 | 词 |
|------|-----|
| 医疗 | 包治、根治、100% 有效、治愈率 |
| 商业 | 全网最低、限时特价（与活动混淆） |
| 歧视 | 田园猫 = 便宜猫 |
| 夸大 | 唯一、独家、第一 |
| 政治 | 政治相关词 |
