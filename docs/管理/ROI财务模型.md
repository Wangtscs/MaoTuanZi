## 五、核心计算公式

### 5.1 月收入

```
月收入 = MAU × 付费率 × 客单价
```

或按收入来源拆分：

```
月收入 = 单次付费收入 + 会员订阅收入 + 套餐收入 + CPS 收入
```

### 5.2 单位经济模型

```
LTV = ARPU × 平均留存月数 × 毛利率

毛利率 = (月收入 - 月变动成本) / 月收入

CAC = 月度营销成本 / 月度新增用户

LTV / CAC 健康值 ≥ 3
```

### 5.3 盈亏平衡

```
盈亏平衡 MAU = 月度固定成本 / (付费率 × 客单价 - 单用户月度变动成本)

盈亏平衡付费用户数 = 月度固定成本 / (客单价 × 毛利率)
```

### 5.4 单用户月度成本上限

```
单用户月度可承受成本 = ARPU × 目标毛利率

示例：若 ARPU = 5 元，目标毛利率 60%，则单用户月度成本 ≤ 2 元
```

## 七、敏感性分析

### 7.1 关键变量对盈亏平衡的影响

| 变量 | 变化 | 对盈亏平衡 MAU 的影响 |
|------|------|----------------------|
| 付费转化率 | +1% | 显著降低 |
| 客单价 | +5 元 | 显著降低 |
| AI 成本 | +50% | 显著升高 |
| 固定成本 | +50% | 线性升高 |

### 7.2 风险场景

| 场景 | 触发条件 | 财务影响 |
|------|----------|----------|
| AI 成本过高 | 单用户成本 > 2 元 | 毛利率被压缩 |
| 转化率低 | 2D 画像转化率 < 3% | 收入不足覆盖固定成本 |
| 用户增长慢 | MAU 增长停滞 | 无法摊薄固定成本 |
| 退款率高 | 退款率 > 10% | 净收入下降 |
