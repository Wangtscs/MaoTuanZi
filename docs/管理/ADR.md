## ADR-001：微信小程序类目选「工具-效率」

- **状态**：✅
- **日期**：2026-08-18

### 背景

上线需要选择微信小程序类目，类目选择影响审核通过率与功能限制。

### 决策

主类目：**工具 → 效率**

### 备选

| 类目 | 优势 | 风险 |
|------|------|------|
| 工具 → 效率 | ✅ 低风险通过率高 | - |
| 工具 → 图像处理 | 适合 | 审核较严 |
| 宠物服务 | 贴切 | 需特殊资质 |
| 宠物医疗 | ❌ 需医疗资质 | ❌ 高风险 |

### 理由

- 低风险通过率高
- 不需要额外资质
- 与功能匹配

## ADR-002：数据存储境内

- **状态**：✅
- **日期**：2026-08-18

### 决策

**所有用户数据存储于境内服务器**。AI 服务商必须为境内服务。

### 理由

- 《个人信息保护法》《数据安全法》要求
- 微信小程序类目要求
- 避免合规风险

### 行动项

- 阿里云 OSS 区域：oss-cn-hangzhou
- MySQL / Redis：境内 ECS
- AI 服务商：仅境内

## ADR-003：3D 模型格式 GLB

- **状态**：✅
- **日期**：2026-08-18

### 决策

- 渲染：`three.js-miniprogram`（微信适配版）
- 文件格式：**GLB**（二进制 GLTF）
- 打印导出：**STL**

### 理由

- GLB 是 glTF 二进制格式，加载快、压缩好
- Three.js 原生支持
- STL 是 3D 打印行业标准

### 代价

- 微信小程序对 GLB 体积有性能要求，> 5MB 需降级
- 已纳入 [`/docs/设计/UIUX视觉规范与组件库.md`](../设计/UIUX视觉规范与组件库.md) § 八 性能降级

## ADR-004：付费墙采用"预览+付费解锁"

- **状态**：✅
- **日期**：2026-08-18

### 决策

- 用户提交图片 → 生成低清带水印预览
- 用户对预览满意 → 付费解锁高清无水印版
- 免费用户仅能查看预览，不可保存

### 理由

- 降低用户付费决策成本
- 避免无效 API 调用
- 转化漏斗清晰

### 备选

| 方案 | 问题 |
|------|------|
| 完全免费体验 | 难以变现 |
| 一次性付费不可见 | 决策成本高 |

### 退款规则

详见 [`/docs/合规法律/21-用户服务协议.md`](../合规法律/21-用户服务协议.md) § 4.4。
