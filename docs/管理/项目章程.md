# 毛团子AI · 项目章程

**版本**：V1.1 | **更新日期**：2026-08-18 | **关联文档**：`prd2.md`、`docs/管理/MVP范围摘要.md`

> 1-2 人独立开发项目的**顶层章程**。任何超出章程的范围、预算或周期，都需要重新审视。

---

## 一、项目愿景

成为养宠人手机里**好用、好看、有温度**的常备工具，用 AI 降低科学养宠门槛，为宠物主创造情感价值，打造小而美的垂直宠物 AI 品牌。

---

## 二、项目目标

### 2.1 短期目标（0-2 个月）

- 上线 MVP 微信小程序，验证核心付费转化
- 获取 500+ 种子用户
- 验证 2D AI 画像付费转化率是否可达 3-5%

### 2.2 中期目标（3-6 个月）

- 完善养宠工具矩阵和轻社交功能
- 月活用户达到 3000+
- 会员付费率达到 3-8%
- 实现正向现金流

### 2.3 长期目标（6-12 个月）

- 上线 3D 萌宠数字手办，建立差异化壁垒
- 形成「2D 颜值 + 3D 互动 + 工具服务」的完整产品矩阵
- 高阶付费用户占比达到 10-15%

---

## 三、范围边界

### 3.1 范围内（MVP 期）

- 微信小程序端用户系统（微信登录、隐私协议、宠物档案）
- 2D AI 宠物画像生成与付费解锁
- 单次付费 + 月卡会员体系
- 微信支付对接
- 我的作品、订单管理、个人中心
- 基础症状查询和喂养方案（含免责声明）

### 3.2 范围外（MVP 期，明确不做）

| 不做 | 原因 |
|------|------|
| 宠物电商交易 | 竞争激烈、SKU 复杂 |
| 宠物医疗诊疗 | 合规风险高、需特殊资质 |
| 通用 AI 工具 | 非垂直、无差异化 |
| 跨端独立 APP | MVP 期微信小程序足够 |
| 自研 3D 算法 | 调用成熟 API |
| 3D 数字手办 | 成本高，阶段 3 再验证 |
| 萌宠广场 / 社交 | 审核成本高，阶段 2 再做 |
| 季卡 / 年卡 / 组合套餐 | MVP 期只验证月卡和单次 |

详细范围见 [`docs/管理/MVP范围摘要.md`](MVP范围摘要.md)。

## 四、关键约束

| 约束类型 | 内容 |
|----------|------|
| 团队规模 | 1-2 人独立开发，后期可扩展到 3-4 人 |
| 开发周期 | MVP 2 周，完整功能 3 个月，正式上线 4 个月 |
| 月度预算 | MVP 期 ≤ 2000 元/月 |
| 技术栈 | 微信原生小程序 + NestJS + Python FastAPI + MySQL + Redis |
| 部署方式 | MVP 单机 Docker Compose |
| 合规要求 | 数据境内存储，AI 服务商境内，健康内容不越界 |

## 五、成功标准

### 5.1 产品成功标准

| 阶段 | 时间 | 核心指标 |
|------|------|---------|
| MVP | 0-2 月 | 付费转化率 ≥ 3%（保守）/ ≥ 5%（乐观），种子用户 500+ |
| 成长 | 3-6 月 | MAU 3000+，月收入 ≥ 6000 元，次日留存 ≥ 30% |
| 成熟 | 6-12 月 | MAU 50000+，月收入 ≥ 5 万元 |

> ⚠️ 上述数字需根据实测调整。

### 5.2 技术成功标准

| 指标 | 目标 |
|------|------|
| 小程序首屏加载 | ≤ 3 秒（MVP 期）/ ≤ 2 秒（正式上线） |
| API P99 延迟 | ≤ 500ms |
| 2D 画像生成时间 | ≤ 15 秒 |
| 支付成功率 | ≥ 95% |

## 六、决策原则

1. **YAGNI**：不写暂时不需要的代码
2. **数据驱动**：产品决策必须有数据支撑
3. **用户体验**：核心功能先做到极致
4. **成本可控**：AI 调用是主要成本，必须严格限流和计费
5. **合规底线**：健康内容不越界，用户数据不出境
6. **文档先行**：重大变更必须先更新文档，再写代码

---

## 七、决策机制

| 决策类型 | 决策者 | 决策依据 |
|----------|--------|---------|
| 产品功能增删 | 产品负责人 | 用户价值、MVP 范围、开发成本 |
| 技术架构变更 | 技术负责人 | ADR 流程、性能/成本约束 |
| AI 服务商选型 | 技术 + 产品共同决策 | 实测效果、成本、稳定性 |
| 发布上线 | 产品 + 技术共同决策 | 测试通过、验收标准满足 |
| 预算超支 | 项目负责人 | ROI 分析、阶段目标 |

---

## 八、主要风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| AI 生成效果不达预期 | 用户不付费 | 多测几家服务商，MVP 期只保留效果最好的风格 |
| 微信审核不通过 | 无法上线 | 选择低风险类目，避免医疗/社交敏感功能 |
| AI 成本过高 | 亏损 | 免费用户仅低清水印，严格控制免费额度 |
| 转化率低于预期 | 商业模式不成立 | 2 周内未达 3% 转化率，暂停扩张，优化定价/风格 |
| 3D 技术不成熟 | 阶段 3 延期 | 阶段 3 前先做充分技术验证，不达标则推迟 |

---

## 九、退出条件

以下情况考虑停止项目：

- 6 个月内付费转化率 < 1%
- 持续亏损 > 10 万元
- 创始人精力不足或方向调整
