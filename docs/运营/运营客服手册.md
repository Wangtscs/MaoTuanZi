## 二、客服工作规范

### 2.1 响应时效

| 优先级 | 首响 | | 关闭 |
|--------|------|------|
| P0（生产不可用）| 5 分钟 | | 30 分钟 |
| P1（核心功能故障）| 15 分钟 | | 4 小时 |
| P2（非核心）| 30 分钟 | | 24 小时 |
| P3（建议）| 2 小时 | | 7 天 |

### 2.2 沟通原则

- 用用户昵称称呼
- 复述问题确认理解
- 提供方案而非推卸
- 闭环确认（"问题解决了吗？"）

### 2.3 禁止行为

- ❌ 医疗建议（详见 `/docs/合规法律/20-隐私政策.md` §7）
- ❌ 推荐药品 / 剂量
- ❌ 承诺超出权限的内容（如退款超规则）
- ❌ 引导用户私下交易
- ❌ 泄露其他用户信息

## 三、FAQ（常见问题标准回复）

> 以下 FAQ 基于**已上线产品的常见问题类型**预判，**真实上线后需根据实际用户反馈补充**。

### 3.1 账号与登录

**Q：忘记账号怎么办？**
A：本产品使用微信一键登录。如微信账号更换，在小程序内 → 我的 → 设置 → 账号问题，提交客服申请。

**Q：怎么注销账号？**
A：我的 → 设置 → 账号注销 → 阅读须知 → 输入验证码。**15 个工作日内完成**，期间可登录撤销。

**Q：一个微信能登录几个账号？**
A：一个微信绑定一个毛团子账号。

### 3.2 宠物档案

**Q：最多几只宠物档案？**
A：免费 2 只，会员无上限。升级路径：我的 → 会员中心。

**Q：删除宠物档案会同时删除作品吗？**
A：**会**。该宠物的所有作品、记录同步删除，操作前请确认。

### 3.3 AI 画像 / 3D

**Q：生成效果不满意？**
A：24 小时内、未分享、未使用可申请退款，每月限 1 次。详见 `/docs/合规法律/21-用户服务协议.md` §4.4。

**Q：为什么不"像"？**
A：AI 效果受照片清晰度、角度、毛色影响。建议：
- 正面清晰、光线充足
- 单只宠物、主体居中、无遮挡
- 重试其他风格

**Q：会员有多少免费额度？**
A：见 `/docs/合规法律/21-用户服务协议.md` §4.1 定价表。

### 3.4 喂养方案

**Q：方案准确吗？**
A：基于宠物档案 + 喂养知识库生成。**仅供参考**，不构成兽医诊断。涉及健康问题请咨询兽医。

**Q：方案能调整吗？**
A：付费后支持 ≤3 次免费调整。

### 3.5 支付与退款

**Q：哪些可退款？**
A：详见 `/docs/合规法律/21-用户服务协议.md` §4.4。简表：

| 商品 | 可退 |
|------|------|
| 2D 画像（24h 内） | ✅ |
| 3D 手办（24h 内） | ✅ |
| 喂养方案 | ❌ |
| 会员 | ❌ |
| 套餐 | ❌ |

**Q：退款多久到账？**
A：微信支付原路退回，通常 **1-3 个工作日**。

### 3.6 广场

**Q：为什么没有评论？**
A：广场**仅有点赞功能**（详见 PRD V2.0 §三 §3.5.1），刻意降低社交压力。

**Q：发的内容被下架？**
A：触发内容审核（违规、低俗、非自家宠物、商业广告）。详见 `/docs/合规法律/21-用户服务协议.md` §六。

### 3.7 技术问题

**Q：白屏 / 加载不出？**
A：
1. 关闭小程序重新进入
2. 检查微信版本（需 ≥8.0）
3. 切换网络（WiFi ↔ 4G）
4. 仍有问题提交反馈：我的 → 设置 → 意见反馈

## 四、特殊场景处理

### 4.1 医疗咨询

- **绝不**给出医疗建议、推荐药品、剂量指导
- 标准话术：

  > 宠物出现 [症状] 请立即前往正规宠物医院就诊。本服务的建议仅供参考。

- 推送症状查询结果页（不收费）

### 4.2 退款争议

| 情况 | 处理 |
|------|------|
| 符合退款规则 | 引导用户提交退款申请 |
| 不符合规则 | 礼貌拒绝 + 引用协议条款 + 提供其他补偿方案（如重新生成） |
| 用户不满 | 升级到客服主管 |

### 4.3 用户要求加微信

- ✅ 客服工作微信：可加
- ❌ 不接受私下交易、承诺超出权限

### 4.4 误生成违规内容

1. 立即道歉
2. **不扣除额度**
3. 重新生成
4. 上报技术修复 Prompt

### 6.1 四类用户

| 层级 | 定义 | 策略 |
|------|------|------|
| 新用户 | 注册 ≤ 7 天 | 首单优惠引导 |
