# 毛团子AI · 上线检查清单

**版本**：V1.0 | **更新**：2026-08-18

> 上线前必须 **100% 通过** 所有检查项。**禁止跳过任何 P0 项**。

---

## 一、合规与法务（P0，必须）

- [ ] 微信小程序账号已认证（企业 / 个体工商户主体）
- [ ] 小程序类目已确认（建议：工具-效率）
- [ ] 隐私政策已在小程序后台填写并发布
- [ ] 用户服务协议已在小程序后台填写并发布
- [ ] 协议弹窗首次访问触发，用户必须同意
- [ ] 协议版本变更记录在 `agreements_log` 表
- [ ] 内容安全审核 API 已接入（机审）
- [ ] 医疗免责声明已在所有健康相关页面顶部固定

## 二、安全（P0）

- [ ] 所有 API 走 HTTPS / TLS 1.2+
- [ ] JWT + Refresh Token 已实现
- [ ] 敏感接口签名校验
- [ ] SQL 注入防护（ORM 参数化）
- [ ] XSS 防护（输出转义）
- [ ] CSRF 防护（SameSite Cookie / Token）
- [ ] 文件上传类型白名单 + 大小限制
- [ ] OSS 私有读 + 签名 URL
- [ ] 密钥从 KMS 注入，未硬编码

## 三、功能完整性（P0）

- [ ] 用户系统（登录、注册、注销）
- [ ] 宠物档案 CRUD
- [ ] AI 画像生成（核心爆品）
- [ ] 喂养方案生成（信任型）
- [ ] 症状查询（引流）
- [ ] 单次付费流程
- [ ] 月卡会员购买
- [ ] 退款流程（24h 内）
- [ ] 广场浏览 + 点赞

## 四、性能（P0）

- [ ] 首页首屏 ≤ 2s（4G 网络）

## 十三、上线后 7 天必看指标

| 指标 | 阈值 | 动作 |
|------|------|------|
| DAU | > 0 | - |
| 注册转化率 | ≥ 30% | < 30% → 优化引导 |
| 付费转化率 | ≥ 5% | < 5% → 调价 / 调权益 |
| AI 任务成功率 | ≥ 85% | < 85% → 切备用服务商 |
| 退款率 | ≤ 10% | > 10% → 紧急排查 |
| API P99 | ≤ 1s | > 1s → 扩容 |
| 投诉量 | 日增 ≤ 50% | 超阈值 → 立即响应 |
