## 四、数据存储

### 4.1 存储地点

您的个人信息**仅存储于中国境内的服务器**。

### 4.2 存储期限

| 数据类型 | 存储期限 |
|---------|---------|
| 账号基本信息 | 账号存续期间 |
| 宠物档案 | 您删除前；账号注销后 30 天内彻底删除 |
| AI 生成作品 | 您删除前；账号注销后 30 天内彻底删除 |
| 订单 / 支付 | ≥ 10 年（合规要求）|
| 聊天 / 客服 | 投诉处理完毕后 3 年 |
| 日志 | 6 个月 |

超过期限后，我们将**删除或匿名化处理**。

### 4.3 安全措施

| 维度 | 措施 |
|------|------|
| 传输 | HTTPS / TLS 1.2+ |
| 存储 | 敏感字段 AES-256 加密 |
| 访问 | 最小权限、操作留痕 |
| 监控 | 异常访问告警 |
| 备份 | 每日全量 + 异地复制 |

### 4.4 安全事件处置

发生安全事件时，我们将：

1. 立即启动应急预案
3. 在 **72 小时内** 通知您和监管机构
3. 告知您事件情况、可能影响及应对措施

## 五、您的权利

依据《个人信息保护法》，您享有：

### 5.1 查阅与复制

路径：「个人中心 → 我的资料 / 我的宠物 / 我的作品 / 订单」

### 5.2 更正与补充

路径：「个人中心 → 编辑」

### 5.3 删除

您可在以下情形中要求删除：

- 处理目的已实现、无法实现或不再必要
- 我们停止提供服务，或您撤回同意
- 处理违反法律法规或约定

路径：「个人中心 → 删除」

### 5.4 账号注销

路径：「个人中心 → 设置 → 账号注销」

- 注销审核：**15 个工作日** 内完成
- 注销后会员权益、订单历史**不可恢复**
- 注销后个人信息将被删除或匿名化

### 5.5 撤回同意

- 关闭对应功能（如位置、相机、相册）
- 关闭订阅消息
- 注销账号

撤回不影响撤回前已进行的处理。

### 5.6 投诉

如有问题，请通过「九、如何联系我们」投诉，我们将在 **15 个工作日内**回复。

## 七、医疗与健康类信息

毛团子AI 提供的「症状护理参考」「个性化喂养方案」内容**仅供参考**，**不构成兽医诊断或医疗建议**。

- 严格遵守：不输出诊断结论、药品推荐、剂量指导
- 所有医疗相关页面顶部固定免责声明
- 过敏史、症状描述仅用于生成参考，**不用于商业推广**
- 宠物持续不适请**立即前往正规宠物医院**
