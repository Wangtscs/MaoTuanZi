# 运维平台（/ops）后端模块说明

本模块在既有「毛团子AI」Spring Boot 单体应用中，新增一套**技术运维/SRE**能力，与原有业务后台（`/admin/**`）、移动端（`/v1/**`）在同一进程、共用数据源，但**接口、表、权限完全隔离**。

## 接口边界

- 所有运维接口前缀 `/ops/**`。
- 鉴权复用业务后台的 Admin JWT（`X-Admin-Token` / `Authorization: Bearer`），由 `AdminAuthInterceptor` + `@RequireAdmin` 保护。
- 登录：`POST /ops/auth/login` 内部复用 `AdminService.login`，登录成功后**校验账号是否具备 `ops.*` 权限**，否则返回 403（FORBIDDEN）。

## 权限码（见 `ErrorCode` / 种子数据）

| 权限码 | 说明 |
| --- | --- |
| `ops.view` | 概览 / 实时监控 / 指标 / 业务巡检 / 实例 |
| `ops.system` | 系统资源 / 线程 |
| `ops.log` | 日志中心（含调整采集级别、清空） |
| `ops.alarm` | 告警规则 / 记录 / 立即评估 |
| `ops.job` | 任务调度 / 记录 / 触发 |
| `ops.datasource` | 数据库 / Redis 状态 |
| `ops.storage` | 存储概览 |
| `ops.audit` | 管理审计 / 内容审计 |
| `ops.config` | 运维配置 |

> `*` 或 `ops.*` 拥有全部权限。默认分配了 `sre` 角色（roleId=5）绑定上述全部权限。

## 默认账号（种子，见 `V2__ops.sql`）

- `admin / admin123`（管理员，具备全部权限，含 `ops.*`）
- `ops / ops123`（仅 SRE 运维权限）

密码哈希为 BCrypt，与业务后台 `AdminService` 同一套加密，可直接在 `/ops/auth/login` 使用。

## 数据表（`ops_*` 前缀）

- `ops_instances`：实例心跳注册（调度器每 15s upsert，10 分钟无心跳标记离线）
- `ops_metric_snapshots`：指标快照（趋势查询来源）
- `ops_alarm_rules` / `ops_alarm_records`：告警规则与触发记录
- `ops_jobs` / `ops_job_records`：定时任务与执行记录

## 内置规则与任务（种子）

- 9 条默认告警规则：JVM 堆、磁盘、错误率、Redis 不可用、DB 连接池、AI 失败率、线程数、HTTP P95、ERROR 日志数。
- 10 个默认任务：`metricsSnapshot`、`dbPing`、`redisPing`、`diskCheck`、`aiTaskTimeout`、`cleanupIdempotency`、`cleanupSnapshots`、`cleanupJobRecords`、`cleanupUploads`、`cleanupInstances`，以及 `alarmEvaluate`（默认**关闭**，需手动开启）。

## 采集机制（进程内，无外部 APM）

- **HTTP 指标**：`OpsMetricsInterceptor` 全局拦截，记录 QPS、错误率、P95/P99、慢请求、按端点排行。
- **日志**：`OpsLogAppender` 以编程方式挂到 Logback ROOT，写入内存环形缓冲（容量 3000）；前端可实时检索、调整采集级别。
- **系统指标**：`OperatingSystemMXBean`、Hikari 连接池、Redis `INFO`、磁盘。
- **调度**：`OpsScheduler` 用 `CronExpression`（秒在前的 6 段 cron）+ 4 线程池，每 5s 扫描待执行任务、每 60s 评估告警，不依赖 Quartz/XXL-JOB。

## 编译与运行

> 本机 Maven 启动器（classworlds）损坏，使用下述方式编译（JDK 21）：
```bash
MH=/d/apache-maven-3.9.8-bin/apache-maven-3.9.8
BOOT=$MH/local_warehouse/org/codehaus/plexus/plexus-classworlds/2.11.0/plexus-classworlds-2.11.0.jar
java -classpath "$(cygpath -w $BOOT)" \
  -Dclassworlds.conf="$(cygpath -w $MH/bin/m2.conf)" \
  -Dmaven.home="$(cygpath -w $MH)" \
  -Dmaven.repo.local="$(cygpath -w $MH/local_warehouse)" \
  -Dmaven.multiModuleProjectDirectory="$(cygpath -w $PWD)" \
  org.codehaus.plexus.classworlds.launcher.Launcher -o -q -DskipTests compile
```
Flyway 在应用启动时自动执行 `db/migration/V2__ops.sql` 建表并写入种子数据。

## 已知环境修复（本次补齐）

为使整个模块可编译，顺带修复了既有业务代码的依赖版本漂移问题（非本模块代码）：
- `WanxAiProvider`：适配 dashscope-sdk-java 2.16.1 新版 API（`ImageSynthesis(apiKey,model)` + `ImageSynthesisParam.builder()` + `call()`）。
- `OssServiceImpl`：aliyun-sdk-oss 3.17.4 的 `OSS` 不再实现 `AutoCloseable`，改用 `try/finally` + `shutdown()`。
- `ApiResult`：补充 `fail(String)` 重载（默认码 100001）。
- `AiServiceImpl`：`AiStyle.getStyleKey()` → `getCode()`；移除不可达的 `InterruptedException` catch。
