# 毛团子AI · 医疗免责声明使用规范

**版本**：V1.0 | **更新**：2026-08-18

> 毛团子AI **严禁**涉及任何医疗诊断。**所有免责声明必须严格执行**。

---

## 一、必须出现免责声明的场景

| 场景 | 页面 |
|------|------|
| 症状护理参考 | 结果页顶部 |
| 个性化喂养方案 | 结果页底部 |
| 健康日程提醒 | 推送消息正文 |
| 萌宠广场（健康类内容）| 帖子详情页 |
| 用户帮助 | 健康问答章节 |

## 二、免责声明文案（固定）

### 2.1 标准版（症状 / 方案类）

```
⚠️ 本内容仅供参考，不构成兽医诊断、医疗建议或治疗方案。
若宠物出现持续不适、急性症状或疑似中毒，请立即前往正规宠物医院就诊。
```

### 2.2 推送消息版（简短）

```
本提醒基于您设置的健康日程。如宠物不适，请咨询兽医。
```

### 2.3 提醒触发版（强烈提示）

```
⚠️ 本提醒不能替代兽医诊断。如宠物出现以下情况请立即就医：
- 持续呕吐 / 便血
- 精神萎靡超过 24 小时
- 拒食超过 24 小时
- 任何急性症状
```

## 三、文案使用规范

### 3.1 位置

| 页面 | 位置 |
|------|------|
| 结果页 | **顶部固定**（滚动时跟随） |
| 详情页 | 内容下方（折叠可展开） |
| 推送 | 消息正文末段 |
| 帮助页 | 章节开头 |

### 3.2 样式

```css
.disclaimer {
  background-color: #FFF7E6;
  border-left: 4px solid #FAAD14;
  padding: 12px 16px;
  font-size: 12px;
  color: #874D00;
  margin: 16px 0;
}
```

- 背景：浅黄
- 左边框：警示色
- 字号：12px（不要太小）
- 颜色：深橙（不要用红，红=错误）

### 3.3 禁用行为

- ❌ 不得使用户可关闭免责声明（必须始终可见）
- ❌ 不得缩小到看不清
- ❌ 不得藏在页面底部
- ❌ 不得用浅色文字（对比度 ≥ 4.5:1）

## 五、紧急情况触发词

以下关键词出现时，**必须**在 AI 输出后追加：

```
"持续呕吐" "便血" "精神萎靡" "拒食" "急性" "中毒" "抽搐" "昏迷"
```

AI 网关 Prompt 模板：

```typescript
const SYMPTOM_KEYWORDS = ['持续呕吐', '便血', '精神萎靡', '拒食', '急性', '中毒', '抽搐', '昏迷'];

function shouldAddEmergencyWarning(content: string): boolean {
  return SYMPTOM_KEYWORDS.some(k => content.includes(k));
}

if (shouldAddEmergencyWarning(aiOutput)) {
  aiOutput += '\n\n⚠️ 宠物出现上述症状请**立即前往正规宠物医院就诊**。';
}
```
