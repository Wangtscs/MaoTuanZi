## 一、审核范围

| 对象 | 审核方式 |
|------|---------|
| 用户昵称 | 机审 |
| AI 生成内容（图像/3D/文案） | 机审（前置展示前） |

## 三、机审策略

### 3.1 接入内容安全 API

**微信小程序内容安全**（首选，免费）：

```typescript
async function checkImage(imageUrl: string): Promise<boolean> {
  const accessToken = await getWechatAccessToken();
  const res = await axios.post(
    `https://api.weixin.qq.com/wxa/media_check_async?access_token=${accessToken}`,
    {
      media_url: imageUrl,
      media_type: 1,  // 1=图片
      version: 2,
      scene: 2       // 2=UGC
    }
  );
  return res.data.errcode === 0;  // 通过
}
```

**阿里云内容安全**（备用，按调用计费）：

```typescript

```

## 四、抽检机制

| 内容类型 | 抽检比例 |
|---------|---------|
| 萌宠广场已发布 | 5% / 日 |
| AI 生成的图像 | 1% / 日 |
| AI 生成的 3D 模型 | 5% / 日 |
| 用户昵称 | 0.1% / 日 |

人工审核员：**1 人轮值**（初期可由创始人承担）

## 五、违规处理

### 5.1 内容层面

| 违规 | 处理 |
|------|------|
| 机审拦截 | 直接拒绝（不消耗额度）|
| 抽检发现违规 | 立即下架 + 通知用户 |
| 用户举报核实 | 立即下架 + 处理用户 |

### 5.2 用户层面

| 违规等级 | 处理 |
|---------|------|
| 轻微（首次）| 警告 + 通知 |
| 较重（重复）| 禁言 7 天 |
| 严重（多次）| 永久封禁 |
| 极严重（违规）| 永久封禁 + 报告 |

## 六、用户举报通道

- 小程序内：每个帖子右上角"..." → 举报
- 举报分类：色情 / 暴力 / 商业 / 侵权 / 其他
- 处理时效：≤ 24 小时

## 七、医疗与健康特殊规则

### 7.1 严格禁止

- ❌ 推荐具体药品（含剂量）
- ❌ 疾病诊断
- ❌ 治疗方案
- ❌ 替代兽医的专业建议

### 7.2 允许的内容

- ✅ 通用护理常识
- ✅ 风险提示（"持续不适请就医"）
- ✅ 免责声明置顶

详见 [`/docs/合规/医疗免责声明使用规范.md`](../合规/医疗免责声明使用规范.md)。

## 八、版权合规

- 用户上传的图片必须确认**拥有版权或获授权**
- AI 生成内容的使用规则详见 [`/docs/合规法律/21-用户服务协议.md`](../../合规法律/21-用户服务协议.md) § 五

## 九、未成年人保护

- 任何未成年人相关违规内容**直接拒绝**
- 平台不向 14 岁以下用户提供服务
- 注销账号后 30 天内彻底删除数据

## 十、记录与审计

所有审核动作必须记录：

```sql
CREATE TABLE audit_logs (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT,
  content_type VARCHAR(32),
  content_id BIGINT,
  check_type VARCHAR(32),  -- machine / manual / report
  check_result VARCHAR(16),  -- pass / block / report
  reason VARCHAR(256),
  operator VARCHAR(64),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

保留 ≥ 6 个月以备合规审查。
