# 毛团子AI · 数据主体权利响应流程

**版本**：V1.0 | **更新**：2026-08-18

> 依据《个人信息保护法》第 44-50 条，用户享有知情、决定、查阅、复制、更正、删除、解释等权利。本文定义响应流程。

---

## 一、权利矩阵

| 权利 | 路径 | 响应时效 |
|------|------|---------|
| 知情 | 隐私政策 | 即时 |
| 决定 | 注册时选择授权 | 即时 |
| 查阅 | 个人中心各模块 | 即时 |
| 复制 | 个人中心 → 数据导出 | ≤ 15 工作日 |
| 更正 | 个人中心 → 编辑 | 即时 |
| 删除 | 个人中心 → 删除 / 注销 | ≤ 15 工作日 |
| 解释 | 客服渠道 | ≤ 15 工作日 |
| 拒绝 | 退出 / 注销 | 即时 |

## 二、查阅权

### 2.1 触发

- 用户主动查阅 → 个人中心各模块
- 用户申请复制 → 个人中心 → 设置 → 数据导出

### 2.2 处理

```typescript
// 用户数据导出（GET /v1/users/me/export）
async function exportUserData(userId: number) {
  const data = {
    user: await getUser(userId),
    pets: await getPets(userId),
    works: await getWorks(userId),
    orders: await getOrders(userId),
    health_reminders: await getHealthReminders(userId),
    weight_logs: await getWeightLogs(userId),
    journal_entries: await getJournalEntries(userId),
    feedings: await getFeedings(userId),
    square_posts: await getSquarePosts(userId),
    checkins: await getCheckins(userId),
    notifications: await getNotifications(userId)
  };

  // 生成 JSON 文件
  const json = JSON.stringify(data, null, 2);
  const filename = `maotuanzi-export-${userId}-${Date.now()}.json`;

  // 上传到 OSS（私有 Bucket）
  await uploadToOSS(filename, json);

  // 返回签名 URL（24h 有效）
  return getSignedUrl(filename, 86400);
}
```

### 2.3 字段

导出包含：
- ✅ 用户基本信息
- ✅ 宠物档案
- ✅ 作品
- ✅ 订单 / 支付记录
- ✅ 健康提醒 / 体重 / 时光
- ✅ 广场帖子
- ❌ AI 生成中（task）的中间产物
- ❌ 已删除超过 30 天的数据

## 三、更正权

### 3.1 可更正字段

- ✅ 昵称、头像、宠物昵称、宠物头像
- ✅ 宠物档案字段（品种、体重、生日等）
- ❌ openid（系统标识，不可改）
- ❌ 历史订单金额（不可改）
- ❌ 注册时间（不可改）

### 3.2 处理路径

```bash
PATCH /v1/users/me        # 用户信息
PATCH /v1/pets/{id}       # 宠物档案
```

## 四、删除权

### 4.1 单项删除

| 对象 | 路径 | 限制 |
|------|------|------|
| 单个宠物 | DELETE /v1/pets/{id} | 级联删除该宠物所有作品 |
| 单个作品 | DELETE /v1/works/{id} | 软删除，30 天后硬删 |
| 单个帖子 | DELETE /v1/square/posts/{id} | 软删除 |
| 单条时光 | DELETE /v1/tools/journal/{id} | 立即删除 |
| 单次提醒 | DELETE /v1/tools/health-reminders/{id} | 立即删除 |

### 4.2 账号注销（最彻底）

```
POST /v1/users/me/cancel
Body: { reason: "no_need" }

流程：
1. 校验账号状态（无未完成订单、未结算退款）
2. 标记 status=2, deleted_at=now()
3. 立即隐藏所有 UGC
4. 15 天后定时任务硬删（用户可登录撤销）
5. 通知用户
```

## 五、解释权

### 5.1 触发场景

- 用户询问"为什么给我推送这个"
- 用户询问"AI 为什么会推荐这种喂养方案"
- 用户询问"为什么我的内容被下架"

### 5.2 处理

- ≤ 15 个工作日
- 通过客服渠道回复
- 涉及算法的，应说明**大致原理**（不必透露商业机密）

## 六、未支付订单的特殊处理

用户申请注销时若有未支付订单：

| 状态 | 处理 |
|------|------|
| 待支付 | 提示用户先关闭订单 |
| 已关闭 | 允许注销 |
| 退款中 | 等待退款完成后再注销 |
