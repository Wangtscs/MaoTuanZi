## 四、质量原则

每份文档必满足：
1. **不写套话**——删除"应当/建议/考虑"
2. **不编数字**——所有估算标"待实测"
3. **✅🟡❌ 标签**——明确内容性质
4. **未决问题清单**——文档结尾明确"待实测/待决策"
5. **引用真实**——引用的资源必须存在
6. **可执行**——命令/脚本可直接运行

## 五、风险与缓解

| 风险 | 缓解 |
|------|------|
| Token 消耗过大 | 每份控制在 8-15 KB |
| 文档互相引用失效 | 每份结尾标注"相关文档" |
| 重复内容 | 通过合并避免（如 B8/B9） |
