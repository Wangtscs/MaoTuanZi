# 毛团子AI · 测试计划与用例

**版本**：V2.1 | **更新日期**：2026-08-18 | **关联文档**：`/.github/workflows/ci.yml`、`docs/管理/MVP范围摘要.md`、`docs/设计/状态机与业务规则汇总.md`

> 本文档定义毛团子AI 的测试策略、覆盖范围和关键用例。**P0 用例必须在每次发版前 100% 通过**。

---

## 一、测试策略

### 1.1 测试金字塔

```
       /\          E2E（少量，覆盖核心路径）
      /  \
     /----\
    /      \      集成测试（API 层）
   /--------\
  /          \    单元测试（业务逻辑）
 /____________\
```

### 1.2 各层目标

| 测试层 | 占比 | 目标 | 工具 |
|--------|:---::|------|------|
| 单元测试 | 60% | 覆盖核心业务逻辑 | Jest / pytest |
| 集成测试 | 30% | 覆盖 API 接口 | Jest + supertest |
| E2E 测试 | 10% | 覆盖 2-3 条核心用户路径 | miniprogram-automator |

### 1.3 优先级定义

| 优先级 | 含义 | 通过要求 |
|:------:|------|----------|
| P0 | 阻塞上线的核心功能 | 100% 通过 |
| P1 | 重要功能 | ≥ 90% 通过 |
| P2 | 增强功能 / 边缘场景 | ≥ 70% 通过 |

## 三、测试数据准备

| 账号类型 | 用途 |

### 3.3 测试图片规范

| 图片 | 规格 | 用途 |
|------|------|------|
| 成功图 | 1080×1080，JPEG，≤ 2MB，正面全身 | 正常生成 |

| 大文件 | 15MB，JPEG | 文件大小超限 |
| 非宠物图 | 风景照 | 未检测到宠物 |
