## 六、生产环境部署

**禁止**把生产 KEY 写入代码或 `.env` 文件。使用以下方式之一：

### 方案 A：阿里云 KMS（推荐）

```bash
# 启动时从 KMS 拉取
node scripts/fetch-secrets.js production
```

脚本需在每次容器启动前运行。

### 方案 B：Docker Secrets

```yaml
secrets:
  jwt_secret:
    file: ./secrets/jwt_secret.txt
services:
  api:
    secrets: [jwt_secret]
```

## 七、本地开发快速生成

生成 `.env.local`：

```bash
cp .env.example .env.local

# 生成 JWT 密钥
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# 开发期可启用 MOCK 模式
echo "MOCK_MODE=true" >> .env.local
```
