## 二、微信生态

### 2.1 账号申请

| 账号 | 用途 | 申请地址 |
|------|------|---------|
| 微信小程序 AppID | 小程序身份 | https://mp.weixin.qq.com |
| 微信支付商户号 | 支付能力 | https://pay.weixin.qq.com |
| 微信开放平台账号 | UnionID 互通（多端）| https://open.weixin.qq.com |

### 2.2 主体类型选择

| 类型 | 限制 | 建议 |
|------|------|------|
| 企业 | 功能最全 | ✅ **首选** |
| 个体工商户 | 大部分功能可用 | ✅ 备选 |
| 个人 | **不支持支付、订阅消息**| ❌ 不适合商业项目 |

### 2.3 接入步骤

**步骤 1：注册小程序账号**

- 准备：营业执照、对公账户、邮箱

**步骤 2：选择类目**

| 类目 | 风险 | 适用 |
|------|------|------|
| 工具 → 效率 | 低 | ✅ **推荐** |
| 工具 → 图像处理 | 低 | ✅ 备选 |
| 宠物服务 | 中（需资质） | ⚠️ |
| 宠物医疗 | 高（需特殊资质） | ❌ 不适合 |

**步骤 3：配置服务器域名**

开发设置 → 服务器域名：
- request 合法域名：`https://api.maotuanzi.ai`
- uploadFile 合法域名：`https://oss-xxx.aliyuncs.com`
- downloadFile 合法域名：同上

**步骤 4：保存凭证**

```
WECHAT_APP_ID=wx...
WECHAT_APP_SECRET=xxx    # 重置后立即失效，注意保存
```

### 2.4 一键登录接入

**小程序端**：

```typescript
wx.login({
  success: ({ code }) => api.post('/v1/auth/wx-login', { code })
});
```

**服务端**：

```typescript
const { openid, session_key, unionid } = await axios.get(
  `https://api.weixin.qq.com/sns/jscode2session?appid=${appId}&secret=${appSecret}&js_code=${code}&grant_type=authorization_code`
);
```

### 2.5 微信支付

**申请条件**：
- 企业 / 个体工商户主体
- 营业执照
- 对公账户
- 经营类目符合微信要求

**接入流程**：

```
① 申请商户号 → ② 开通 JSAPI / 小程序支付 → ③ 配置 API v3 密钥 → ④ 下载商户证书 → ⑤ 后端对接
```

**配置**：

```
WECHAT_PAY_MCH_ID=xxx           # 商户号
WECHAT_PAY_API_KEY=xxx          # API v3 密钥（32 位）
WECHAT_PAY_CERT_PATH=./certs/apiclient_cert.pem
WECHAT_PAY_KEY_PATH=./certs/apiclient_key.pem
WECHAT_PAY_NOTIFY_URL=https://api.maotuanzi.ai/v1/webhooks/wx-pay
```

**支付流程**：

```
[小程序] 创建订单 → 后端返回 prepay_id
    ↓
[小程序] wx.requestPayment({ ... }) 唤起支付
    ↓
[用户] 输入密码支付
    ↓
[微信] 异步通知 → /v1/webhooks/wx-pay
    ↓
[后端] 验签 + 更新订单 + 发放权益
```

**退款**：

- 调用 `/v3/refund/domestic/refunds` 接口
- 需要原支付单号 + 商户退款单号
- 异步通知到 `/v1/webhooks/wx-refund`

### 2.6 微信订阅消息

**步骤**：
1. 申请模板（一次性订阅 / 长期订阅）
2. 用户主动触发订阅（`wx.requestSubscribeMessage`）
3. 后端发送（一次模板只能发一次）

**发送接口**：

```typescript
await axios.post('https://api.weixin.qq.com/cgi-bin/message/subscribe/send', {
  touser: openid,
  template_id: 'xxx',
  page: 'pages/tools/health-reminders/detail?id=123',
  data: {
    thing1: { value: '疫苗提醒' },
    date2: { value: '2026-08-20' }
  }
}, { params: { access_token: accessToken } });
```

**限制**：
- 一次性订阅：用户主动触发才能发 1 条
- 长期订阅：仅部分类目可用，需特殊申请

## 三、阿里云 OSS

### 3.1 账号与 Bucket

1. 注册阿里云账号 + 实名认证
2. 创建 Bucket：
   - 名称：`maotuanzi-prod`
   - 区域：选离用户最近的（如 `oss-cn-hangzhou`）
   - 存储类型：标准存储
   - 读写权限：**私有**
4. 开通 CDN + 配置跨域

### 3.2 AccessKey 管理

- 创建 RAM 子账号（不要用主账号）
- 仅授权最小权限（如 `AliyunOSSFullAccess`，生产环境更细粒度）
- 使用 **STS 临时访问凭证** 给前端直传

### 3.3 后端 Node.js SDK

```typescript
import OSS from 'ali-oss';

const client = new OSS({
  region: process.env.OSS_REGION,
  accessKeyId: process.env.OSS_ACCESS_KEY_ID,
  accessKeySecret: process.env.OSS_ACCESS_KEY_SECRET,
  bucket: process.env.OSS_BUCKET
});

// 上传
await client.put('uploads/2026/08/18/123/abc.jpg', buffer);

// 签名 URL（私有读）
const url = client.signatureUrl('uploads/.../abc.jpg', { expires: 86400 });
```

### 3.4 前端直传（STS 临时凭证）

```typescript
// 1. 后端签发 STS
const sts = await api.post('/v1/upload/presign', { scene: 'portrait_input' });

// 2. 前端用 STS 直传 OSS
const ossClient = new OSS({
  region: 'oss-cn-hangzhou',
  accessKeyId: sts.accessKeyId,
  accessKeySecret: sts.accessKeySecret,
  stsToken: sts.securityToken,
  bucket: 'maotuanzi-prod',
  secure: true
});

await ossClient.put(objectKey, file);
```

### 3.5 跨域配置

OSS → 跨域设置 → 创建规则：
- 来源：`https://maotuanzi.ai` / `https://servicewechat.com`
- 允许 Methods：`POST, PUT, GET, HEAD`
- 允许 Headers：`*`

### 3.6 CDN 配置

- 域名：`cdn.maotuanzi.ai`
- 回源 OSS
- HTTPS 证书
- 缓存策略：图片 30 天，视频 7 天

### 3.7 访问策略对比

| 路径 | 读写权限 | 访问方式 |
|------|---------|---------|
| `uploads/` 用户上传原图 | 私有 | 签名 URL |
| `works/` 生成结果 | 私有 | 签名 URL |
| `square/` 广场公开图 | 公共读 | CDN |
| `static/` 静态资源 | 公共读 | CDN |

## 四、AI 服务（关键选型）

> ⚠️ **AI 服务商价格、效果、合规性变化快**，本文给出**评估框架**而非结论。**P0 阶段必须实测至少 2 家**。

### 4.1 选型维度

每个 AI 能力都需评估以下维度：

| 维度 | 评估方法 |
|------|---------|
| 效果 | 准备 10 个测试用例，对比输出 |
| 价格 | 跑量测算单任务成本 |
| 稳定性 | 连续调用 100 次的失败率 |
| 延迟 | P50 / P95 / P99 |
| 合规 | 数据是否境内、是否签署协议 |
| 文档 / SDK | 完善度 |
| 客服响应 | 故障处理时效 |

### 4.2 通用大模型（文本生成）

**用途**：症状建议、喂养方案、文案、取名、聊天

**候选服务商**（举例，需实测）：

| 服务商 | 模型示例 | 评估重点 |
|-------|---------|---------|
| 字节豆包 | Doubao-pro | 中文能力、价格 |
| 阿里通义 | Qwen-Max | 中文、生态 |
| DeepSeek | DeepSeek-V3 | 价格、开源可控 |
| 智谱 | GLM-4 | 企业级、API 稳定 |
| OpenAI | GPT-4o（仅境外）| 不推荐（合规） |

**接入示例**（OpenAI 兼容接口）：

```typescript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.LLM_API_KEY,
  baseURL: process.env.LLM_BASE_URL  // 兼容 OpenAI 格式
});

const response = await client.chat.completions.create({
  model: 'doubao-pro-32k',
  messages: [
    { role: 'system', content: '你是宠物健康顾问...' },
    { role: 'user', content: '我家猫最近软便' }
  ],
  temperature: 0.7
});
```

**Prompt 管理**：

- 模板文件：`packages/prompt-templates/`
- 版本控制（Git）
- A/B 测试支持

### 4.3 图生图（2D 画像）

**用途**：宠物画像生成

**候选服务商**（举例）：

| 服务商 | 评估重点 |
|-------|---------|
| 阿里通义万相 | 境内、价格 |
| 字节豆包图像 | 境内、生态 |
| Replicate SDXL | 模型丰富、海外 |
| Stability AI | 模型丰富、海外 |

> **重点评估**「宠物还原度」（五官、毛色相似度）。

**接入流程（异步模式）**：

```
1. POST 创建任务（带输入图 + prompt）
   → 返回 task_id
2. 轮询 GET /tasks/{id}
   → 状态：pending / processing / success / failed
3. success 时下载结果 URL
```

### 4.4 单图 3D 生成（数字手办）

**用途**：3D 手办生成

**候选服务商**（举例）：

| 服务商 | 评估重点 |
|-------|---------|
| Tripo3D | 速度、价格 |
| Meshy | 模型质量 |
| Luma Genie | 还原度 |
| Rodin | 细节 |

> **重点评估**：生成时长、毛发还原度、模型文件大小、是否支持 GLB 格式。

**接入示例**：

```python
import requests

response = requests.post(
    'https://api.tripo3d.ai/v1/tasks',
    json={
        'type': 'image_to_model',
        'image': 'https://oss.../upload/xxx.jpg',
        'format': 'glb'
    },
    headers={'Authorization': f'Bearer {api_key}'}
)
task_id = response.json()['task_id']

# 轮询
while True:
    status = requests.get(f'https://api.tripo3d.ai/v1/tasks/{task_id}').json()
    if status['status'] == 'success':
        glb_url = status['result']['model']['url']
        break
    time.sleep(5)
```

## 八、密钥管理

### 8.1 密钥分级

| 级别 | 例子 | 存储 |
|------|------|------|
| 🔴 核心 | 微信支付 API v3、商户私钥 | 阿里云 KMS |
| 🟠 重要 | 阿里云 OSS、阿里云 SMS | 环境变量 + KMS |
| 🟡 一般 | Sentry、UptimeRobot | 环境变量 |
| 🟢 公开 | AI Provider Key | 环境变量 |

### 8.2 密钥轮换

| 类型 | 周期 |
|------|------|
| 微信 AppSecret | 90 天 |
| 微信支付 API v3 | 365 天 |
| OSS AccessKey | 180 天 |
| AI Provider Key | 90 天 |
| 其他 | 365 天 |

### 8.3 安全规范

- ❌ **禁止** 把密钥 commit 到代码
- ❌ **禁止** 把生产密钥共享到非生产环境
- ✅ **必须** 使用 KMS 管理核心密钥
- ✅ **必须** 在 `.env.example` 提供模板（不放真实值）
- ✅ **必须** 在 CI 中启用密钥泄露扫描（如 `gitleaks`）

### 8.4 `.gitignore`

```
.env
.env.local
*.pem
*.key
secrets/
```

### 8.5 密钥泄露应急

1. 立即撤销 / 重置密钥
2. 检查调用日志，评估影响范围
3. 通知相关方
4. 复盘 + 加固

## 九、降级与熔断

### 9.1 第三方服务降级矩阵

> ⚠️ 主备方案需在 P0 阶段实测后固化。

| 服务 | 主用 | 降级方案 | 触发条件 |
|------|------|---------|---------|
| 微信支付 | 微信支付 | 暂停付费功能 | 微信支付故障 |
| 微信登录 | 微信授权 | 游客模式 | 微信 API 故障 |
| 大模型 | 服务商 A | 服务商 B | A 失败率 > 30% |
| 图生图 | 服务商 A | 服务商 B | A 失败率 > 30% |
| 单图 3D | 服务商 A | 服务商 B | A 失败率 > 30% |
| 宠物识别 | 服务商 A | 服务商 B | A 失败率 > 30% |
| OSS | 阿里云 OSS | 腾讯云 COS | 阿里云 OSS 故障 |
| 短信 | 阿里云短信 | 邮件 | 短信发送失败率 > 30% |

### 9.2 熔断器配置

```python
from pybreaker import CircuitBreaker

ai_breaker = CircuitBreaker(fail_max=5, reset_timeout=60)

@ai_breaker
async def call_llm(prompt: str):
    return await openai.ChatCompletion.create(...)
```

**熔断规则**：
- 连续失败 5 次 → 熔断
- 熔断时长 60s
- 半开探测：通过 → 关闭；失败 → 重置

### 9.3 健康检查脚本

```bash
#!/bin/bash
# health-check.sh
for url in \
  "https://api.weixin.qq.com/cgi-bin/token" \
  "https://dashscope.aliyuncs.com/api/v1/services" \
  "https://api.tripo3d.ai/v1/health"; do
  status=$(curl -s -o /dev/null -w "%{http_code}" "$url")
  if [ "$status" != "200" ]; then
    echo "ALERT: $url returned $status"
  fi
done
```
