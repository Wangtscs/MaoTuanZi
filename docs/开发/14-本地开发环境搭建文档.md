# 毛团子AI · 本地开发环境搭建文档

**版本**：V2.0 | **更新日期**：2026-08-18

> 本文档帮助开发者从零搭建本地开发环境。**预期 1-2 小时**（含下载时间），具体根据网络和机器性能而定。

---

## 一、环境概览

```
开发机
├── 微信开发者工具（小程序 IDE）
├── Node.js 20 + pnpm
├── Python 3.11 + Poetry（AI 网关）
├── Docker / Docker Compose（MySQL + Redis）
├── Git
└── 编辑器（VS Code 推荐）
```

**支持平台**：macOS 13+ / Ubuntu 22.04 / Windows 11 + WSL2 / Windows 11 原生

## 二、基础工具安装

### 2.1 Git

```bash
# macOS
brew install git

# Ubuntu
sudo apt install git

# Windows
winget install Git.Git
```

**全局配置**：

```bash
git config --global user.name "你的名字"
git config --global user.email "your@email.com"
git config --global init.defaultBranch main
git config --global core.autocrlf input  # Windows
git config --global pull.rebase true
```

### 2.2 Node.js（推荐用 nvm）

```bash
# macOS / Linux
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
nvm install 20
nvm use 20
nvm alias default 20

# Windows：使用 nvm-windows
# https://github.com/coreybutler/nvm-windows/releases
```

**包管理器**：

```bash
npm install -g pnpm@9

# 国内镜像（可选）
pnpm config set registry https://registry.npmmirror.com
```

### 2.3 Python（AI 网关用）

```bash
# macOS
brew install python@3.11

# Ubuntu
sudo apt install python3.11 python3.11-venv python3-pip

# Windows：python.org 下载安装
```

**Poetry**：

```bash
curl -sSL https://install.python-poetry.org | python3 -

# 国内镜像
poetry config repositories.pypi https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2.4 Docker

- macOS / Windows：Docker Desktop
- Ubuntu：Docker Engine + Docker Compose

```bash
# 验证
docker --version
docker compose version
```

**国内镜像加速**（编辑 `/etc/docker/daemon.json`）：

```json
{

    "https://mirror.ccs.tencentyun.com",

}
```

下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

- 扫码登录
- 设置 → 安全 → 服务端口：**开启**

## 三、克隆与初始化

### 3.1 克隆代码

```bash
git clone https://github.com/your-org/maotuanzi.git
cd maotuanzi
```

### 3.2 目录结构

```
maotuanzi/
├── apps/
│   ├── miniprogram/          # 微信小程序
│   ├── api/                  # Node.js 后端 API（NestJS）
│   └── ai-gateway/           # Python AI 网关
├── packages/
│   ├── shared-types/         # 共享 TS 类型
│   └── prompt-templates/     # Prompt 模板
├── docs/                     # 文档
├── deploy/                   # 部署脚本
│   ├── sql/
│   │   ├── schema.sql        # 表结构
│   │   └── seed.sql          # 种子数据
│   └── docker/
├── docker-compose.yml        # 本地依赖编排
├── .env.example              # 环境变量模板
└── README.md
```

### 3.3 复制环境变量

```bash
cp .env.example .env.local
# 编辑 .env.local，填入自己的配置
```

> ⚠️ `.env.local` 不要提交到 Git。

## 四、启动本地依赖

### 4.1 启动 MySQL + Redis

`docker-compose.yml` 完整示例：

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: maotuanzi-mysql
    restart: unless-stopped
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: maotuanzi
      TZ: Asia/Shanghai
    command:
      --character-set-server=utf8mb4
      --collation-server=utf8mb4_unicode_ci
      --default-authentication-plugin=mysql_native_password
    volumes:
      - mysql_data:/var/lib/mysql
      - ./deploy/sql:/docker-entrypoint-initdb.d

  redis:
    image: redis:7
    container_name: maotuanzi-redis
    restart: unless-stopped
    ports:
      - "6379:6379"
    command: redis-server --appendonly yes
    volumes:
      - redis_data:/data

volumes:
  mysql_data:
  redis_data:
```

**启动**：

```bash
docker compose up -d

# 验证
docker compose ps
docker compose logs -f mysql  # 查看初始化日志
```

### 4.2 验证 MySQL

```bash
# 进入 MySQL
docker compose exec mysql mysql -uroot -proot123 maotuanzi

# 检查表
SHOW TABLES;

# 退出
exit
```

### 4.3 验证 Redis

```bash
docker compose exec redis redis-cli ping
# 返回 PONG
```

## 五、启动后端 API

### 5.1 安装依赖

```bash
cd apps/api
pnpm install
```

### 5.2 配置环境变量

`apps/api/.env`：

```bash
NODE_ENV=development
PORT=3000

# 数据库
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=root123
DB_NAME=maotuanzi

# Redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379

# JWT
JWT_SECRET=dev-secret-change-me
JWT_EXPIRES_IN=7d
JWT_REFRESH_EXPIRES_IN=30d

# 微信（开发可使用测试号）
WECHAT_APP_ID=wx...
WECHAT_APP_SECRET=...

# OSS（开发可使用测试 Bucket）
OSS_ACCESS_KEY_ID=
OSS_ACCESS_KEY_SECRET=
OSS_BUCKET=maotuanzi-dev
OSS_REGION=oss-cn-hangzhou

# AI 网关地址
AI_GATEWAY_URL=http://localhost:8000
```

### 5.3 数据库迁移

```bash
# 运行迁移
pnpm run db:migrate

# 导入种子数据
pnpm run db:seed

# 查看表
pnpm run db:status
```

### 5.4 启动 API

```bash
pnpm run dev

# 看到以下输出表示成功
[Nest] LOG [NestFactory] Starting Nest application...
[Nest] LOG [InstanceLoader] AuthModule dependencies initialized
...
[Nest] LOG [NestApplication] Nest application successfully started
```

### 5.5 验证 API

```bash
# 健康检查
curl http://localhost:3000/health
# {"status":"ok"}

# Swagger 文档
open http://localhost:3000/docs
```

## 六、启动 AI 网关

### 6.1 安装依赖

```bash
cd apps/ai-gateway
poetry install
poetry shell  # 进入虚拟环境
```

### 6.2 配置环境变量

`apps/ai-gateway/.env`：

```bash
ENV=development
PORT=8000

# Redis（与后端共享）
REDIS_URL=redis://127.0.0.1:6379

# AI 服务商 Key（开发可留空，会走 mock 模式）
DOUBAO_API_KEY=
DASHSCOPE_API_KEY=
TRIPO_API_KEY=
BAIDU_API_KEY=

# Mock 模式（无 Key 时启用）
MOCK_MODE=true
```

### 6.3 启动 AI 网关

```bash
python main.py

# 或开发模式
uvicorn main:app --reload --port 8000
```

### 6.4 验证 AI 网关

```bash
# 健康检查
curl http://localhost:8000/health
# {"status":"ok"}

# API 文档
open http://localhost:8000/docs
```

## 十、常见问题排查

### Q1：小程序无法连接后端

**排查**：
1. 后端是否启动：`curl http://localhost:3000/health`
2. 小程序开发设置 → **不校验合法域名**（勾选）
3. CORS 配置：后端 `app.enableCors({ origin: '*' })`

### Q2：Docker 启动慢

```bash
# 清理
docker system prune -a

# 检查镜像源
cat /etc/docker/daemon.json
```

### Q3：端口冲突

```bash
# macOS / Linux
lsof -i :3306

# Windows
netstat -ano | findstr :3306

# 修改 docker-compose.yml 端口映射
ports:
  - "3307:3306"  # 主机:容器
```

### Q4：依赖安装失败

```bash
# Node.js
pnpm store prune
rm -rf node_modules
pnpm install

# Python
poetry cache clear pypi --all
poetry install
```

### Q5：数据库迁移报错

```bash
# 查看迁移状态
pnpm run db:status

# 回滚上一个
pnpm run db:rollback

# 重置（开发环境）
pnpm run db:reset
```

### Q6：MOCK 模式不生效

确认 `.env` 中 `MOCK_MODE=true`，且 AI Provider 调用前判断该字段。
